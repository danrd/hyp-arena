## Почему вердикт дизайна не сработал на написанных гипотезах (для решения по альтернативам)

На пакете 28 правило кода (есть признак дизайна → вердикт по виду угрозы) расходится с Argon, потому что Argon решает,
отвечает ли конкретный элемент дизайна на конкретную угрозу: контроль есть, но не тот (не тот же индуктор, нет имитирующих
инъекций, активный контроль без тех же датчиков); угрозу снимает измерение в протоколе, а не дизайн; контроль
специфичности стоит на другом шаге; метка угрозы у клеток широкая; в карточке нет полей маскирования, повторности и
контроля специфичности. Для людей вид угрозы почти однозначно задаёт отсекающий элемент (κ 0.46–0.57), для клеток нет
(0.07). Вариант, предложенный пользователю: фиксированный список угроз по системе; для людей вердикт кодом, для клеток и
животных — модель по дословной фразе текста.
