# Archive

What the current system does not use, kept for its ideas and the history of decisions. Nothing here is installed with the
package or tested, except the worked examples of [`docs/method-history.md`](docs/method-history.md) (checked by
`tests/test_manual.py`). The git history has every earlier version.

| Folder | What is in it |
|---|---|
| [`docs/`](docs/README.md) | Documents of method v2 and earlier v3 rules, drafts of specifications, notes on Bio Arena and Co-Scientist |
| [`handoffs/`](handoffs/) | Hand-offs between sessions (2026-10-29 … 2026-11-12): the chain of decisions |
| [`code/`](code/README.md) | Code of method v2 that v3 does not use: the demonstration page and the tournament simulation |
| [`data/demo/`](data/demo/) | Example inputs and runs of the demonstration page |
| [`tasks/`](tasks/) | Task texts for other coding agents (Jules): the LLM catalogue and parts B and C of the knowledge-graph extraction set |

The current method is the [manual](../docs/method-v3-manual.md); checks are in [`specs/`](../specs/README.md), their
calculations in [`scripts/`](../scripts/README.md). Task texts for the outside reader (Argon) and its answers are only in the
private `longevity-kg` (`reviews/argon-<date>/`).
