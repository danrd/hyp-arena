## Реализуемость и готовность вмешательств

- **Fallback в ClinicalTrials.gov до даты `T` для препаратов (`compound`).** Если ChEMBL не вернул подтверждённую
  фазу вещества (`unresolved`, `phase_unknown`, `identity_unverified`, `lookup_failed`), код проверяет
  ClinicalTrials.gov v2 по точному совпадению названия или синонима среди испытаний с `StudyFirstSubmitDate <= T`
  ([`hyparena/tools/clinicaltrials.py`](../../hyparena/tools/clinicaltrials.py), кэш `data/cache/ct_readiness.json`).
  Применяется та же шкала фаз (`4 → 1.0`, `1–3 → 0.5`, `0 → 0.0`, неподтверждённая комбинация ≤ `0.5`).
- **Канал Б (`implementation_readiness/v1`) для нелекарственных вмешательств.** Для устройств, процедур, упражнений,
  диеты, генных и клеточных вмешательств добавлен один вызов ридера по уже собранным аннотациям до `T`
  ([`hyparena/reading/implementation.py`](../../hyparena/reading/implementation.py), шаблон
  `prompts/implementation_readiness/v1.j2`). Статус `demonstrated` (`1.0`) или `conditional` (`0.5`) засчитывается
  только при кодовой проверке дословной цитаты в аннотации; иначе статус автоматически понижается до `missing` (`0.0`).
  Для препаратов (`compound`) сохраняется приоритет регуляторных баз (`ChEMBL + ClinicalTrials.gov`).
- **Разложение реализуемости в отчёте.** Во вкладке «Оценка гипотез» под таблицей показателей выводится блок
  «Из чего складывается реализуемость» (`v3_extra.feasibility_breakdown`): система, длительность, плановая выборка и
  готовность вмешательства (с причиной, PMID при наличии и всплывающими пояснениями по шкале каждого компонента).

## Новизна, альтернативы и клиничность конечной точки

- **Удержание функциональных исходов из ранних звеньев (`paper_outcomes/v2`).** Когда слот исхода пуст и базовая
  лестница выдаёт `new_link` или `new_combination`, перед выставлением высокого уровня проверяются уже найденные
  аннотации ранних звеньев ([`hyparena/reading/paper_outcomes.py`](../../hyparena/reading/paper_outcomes.py), шаблон
  `prompts/paper_outcomes/v2.j2`). Если в аннотации найдено подтверждённое дословной цитатой функциональное или
  клиническое наблюдение того же/смежного вмешательства и домена исхода, уровень новизны понижается до `new_context`
  / `translation` / `analog` без изменения баланса доказательств.
- **Неизвестная новизна `N = None` в ASPID.** В [`hyparena/scoring/aspid_v3.py`](../../hyparena/scoring/aspid_v3.py)
  неизвестная новизна ставится в нижнюю точку шкалы (`new_context`) вместо равномерного розыгрыша по `[0, 1]`
  (среднее `0.50`), чтобы отсутствие данных о новизне не обгоняло доказанный перенос (`translation`).
- **Клиничность конечной точки по системе эксперимента.** В `v3_extra.endpoint_for_experiment` клинические уровни
  (`patient_reported`, `function`, `clinical_event`) применяются только к опытам на людях (`system == "human"`); для
  животных и клеток уровень ограничен `biomarker`.
- **Багфикс чек-листа методологических угроз для клеток.** В
  [`hyparena/alternatives/threats.py`](../../hyparena/alternatives/threats.py) добавлен ключ `"cells": "cells"` в
  словарь `SYSTEM` (ранее был только `"in_vitro"`), что восстановило чек-лист из 6 угроз, флаг `threats_open` и
  `headroom_I` для всех карточек с `system = "cells"`.

## Промпты генерации v3 (`A3` / `BS3`)

- В [`scripts/argon/generation_tasks.py`](../../scripts/argon/generation_tasks.py) добавлен конструктор `build_v3`
  (`--participant a3|bs3`):
  - Общая часть (`A3` и `BS3` одинаково): убрана лазейка про косметическую доработку вмешательства (*«testable change
    to the intervention itself»*), добавлено требование опираться на выполнимые до `T` средства, указывать плановую
    выборку и проверять критические предпосылки.
  - Часть метода (`BS3`): добавлены `n_planned` в `card.decisive_experiment`, `implementation_check` (средство + PMID
    до `T` по плечам), `critical_premise` с полем решения (`keep / narrow / pivot_experiment / drop_and_replace`) и
    `disconfirming_result` в `tested_before_T`.

## Проверки (dev + out-of-sample holdout)

- **`Sol-20` (dev, vs слепой судья v3, 190 пар):** `Funding` ρ вырос с `+0.191` (v3.12) до **`+0.390`**, `Frontier`
  ρ — с `−0.190` до **`+0.126`**, `Evidence` ρ — с `+0.448` до **`+0.452`** (Top-10 `5/10 → 6/10`), корреляция
  `Feas vs J-Testability` — с `−0.176` до **`+0.058`**. Согласие Канала Б на 12 нелекарственных гипотезах:
  `84.6%` (`11/12`, `κ = +0.683`, `missing` recall `7/7 = 100%`, цитаты `6/6`).
- **`10x10-20` (holdout, vs слепой судья v2, 190 пар):** `Funding` ρ вырос с `+0.180` (v3.12) до **`+0.372`**
  (Top-10 `6/10 → 7/10`), `Feas vs J-Testability` улучшилась с `−0.102` до **`−0.067`**, `0/4` ложных срабатываний на
  генных гипотезах, цитаты `6/6`.
- **`pack_26` (holdout, эталон новизны Argon, 30 гипотез):** `paper_outcomes/v2` сохранил `8/9` настоящих
  `new_link / new_combination` (`wkappa 0.371 → 0.327`, `false_high = 0`, 27/27 вызовов без ошибок валидации цитат).
- **Регрессия на реестровых пулах (`prospective-60` и `calibration-73`):** `Evidence` и `Frontier` сохранили
  **10/10** в Топ-10 на обоих пулах; `Funding` — `10/10` и `9/10`.
- Отбракованы по калибровке и не включены: наивный PubMed-поиск готовности нелекарственных средств (ложные совпадения по
  белкам `Cx40`/`connexin-36`), кодовый MeSH + CT.gov для нелекарственных (`0/4` на `Sol-20`) и наивный PubMed-гвард на
  `new_link` (уронил `pack_26` `wkappa` до `0.291` и не поймал `H09`/`H15`).
