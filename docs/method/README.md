# Метод: описание

Здесь лежит только описание метода оценки гипотез — то, по чему работает система и по чему её может повторить человек или
другая модель. Как метод проверяется, — в [`docs/validation/`](../validation/testing.md); код — в
[`hyparena/`](../../hyparena/README.md); исходники схем и скрипты их сборки — в [`scripts/docs/`](../../scripts/docs/).

**Порядок чтения.**

1. [`manual.md`](manual.md) — сводный мануал: все правила метода в сжатом виде, как читать отчёт, известные ограничения и
   состояние проверки. Его достаточно, чтобы применить метод.
2. [`steps.md`](steps.md) и схемы в [`schemes/`](schemes/) — система по шагам на одной странице; самая подробная схема —
   [`schemes/flow_full.png`](schemes/flow_full.png).
3. Мануалы этапов, по порядку схемы — подробности, источники решений и слабые места каждого этапа:

| Этап | Мануал |
|---|---|
| карточка гипотезы | [`card.md`](card.md) |
| поиск статей | [`search.md`](search.md) |
| чтение и записи | [`reading.md`](reading.md) |
| вес записи, сила звена, баланс доказательств, ворота | [`evidence.md`](evidence.md) |
| новизна | [`novelty.md`](novelty.md) |
| эксперимент, альтернативы, информативность | [`alternatives.md`](alternatives.md) |
| показатели, профили, ранжирование | [`ranking.md`](ranking.md) |
| улучшения и версии гипотез | [`versions.md`](versions.md) |

4. [`foundations.md`](foundations.md) — принятые схемы и стандарты, на которые опирается метод.
5. [`changelog-v4.1.md`](changelog-v4.1.md) — изменения текущего выпуска (**Method v4.1**). [`changelog.md`](changelog.md) — полный журнал метода (предыдущие выпуски: [`changelog-v4.0.md`](changelog-v4.0.md), [`changelog-v3.13.md`](changelog-v3.13.md)).

Всё, что меняет метод, сначала записывается в мануал этапа, затем в сводный мануал и в журнал изменений.
