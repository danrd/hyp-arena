## Решения пользователя этого периода (не пересматривать без него)

- Эталон, смешавший относимость и извлечение, — ошибка устройства эксперимента: переделать (новый критерий), это не подгонка.
- Класс эффекта — по правилу А (код по фразе); пороги процентов 5 / 20 — рабочие.
- Разметку эталонов и исходов можно отдавать Argon вручную; проверка кодом и выборочно Claude. Разметку для проверки
  нормализатора (Gemini) — не Argon (та же модель).
- Не уходить от АСПИДа к произведению трёх чисел; новые показатели — по четырём условиям (надёжность, разведение,
  неизбыточность, свой вопрос).
- Роль ИИ — одна метка с цитатой, профиль «инвестор»; без шкалы с проверкой литературы.
- Hypothesis Arena (OHF) — сторонний проект компании: следить и заимствовать, сближения нет.
- Начинать с малых подвыборок; платные шаги — по одному.
- Независимые источники: несколько записей одной статьи или испытания считаются один раз (v3.2 `fold`).
- Тип конечной точки — показатель; лестница `effect_level` отдельной осью не нужна.
- Тренд и генетика — да (генетика пока не прошла по покрытию); сетевая близость — задание для Codex; Endpoint Arena — пока нет.
- Отчёт: широкий читатель, основа лаконичная с пояснениями чисел, подробности — в приложениях, HTML со сворачиванием и
  ссылками, RU/EN опцией; страница — слепок сайта для пула; сайт — живая таблица.
