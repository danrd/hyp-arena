# Карточка гипотезы: состав, происхождение полей, на что опираемся

Черновик 2026-11-12. Модель данных — `hyparena/card/models.py`, спецификация —
[`../spec/hypothesis-card-spec.md`](../spec/hypothesis-card-spec.md), правила — мануал, раздел 3. Схема этапов —
[`flow_full.png`](flow_full.png). Заполненность полей посчитана на 80 сохранённых карточках (59 проспективных
испытаний и 21 испытание пилота бенчмарка v2 — тексты записей ClinicalTrials.gov, `longevity-kg/hypothesis_sources/`;
нормализатор v10, один разбор, до добавления полей дизайна реестра).

## 1. Два слоя и метки происхождения

Карточка — **заявленный слой**: только то, что говорит текст гипотезы. Всё, что система добавляет потом, — **проверенный
слой** и добавки; они хранятся отдельно и в отчёте показываются отдельно.

| Метка | Что значит | Кто делает | Чем проверено |
|---|---|---|---|
| **из текста, с опорой** | у значения есть дословная фраза текста | LLM-нормализатор (два разбора) | код сверяет дословность; без фразы утверждение выбрасывается (утверждения, роль ИИ) |
| **из текста, без опоры** | LLM записала значение по тексту, фразы нет | LLM-нормализатор | ничем, кроме схемы и закрытых списков (PICO, эксперимент, тип гипотезы, суть одной фразой) |
| **из полей реестра** | взято кодом из полей ClinicalTrials.gov на дату T | код (`benchmark_run._ctgov_design`) | детерминировано |
| **по правилу кода** | выведено правилом, без модели | код | тесты (`tests/`) |
| **добавлено LLM** | не из текста: суждение модели после поиска | LLM (отдельный вызов) | по мануалу: дословная опора где возможно; согласие с Argon |
| **вычислено** | формула мануала | код | тесты; пересчёт в проверке отчётов |
| **написано писателем** | текст версии или сгенерированной гипотезы | LLM-писатель (эволюция, генерация) | правила раздела 11 |

## 2. Паспорт полей

«Заполнено» — доля из 80 карточек, где значение не «unknown» (для утверждений — из 208 утверждений).

### 2.1 Из текста (нормализатор, `normalize_card/v11`)

Дословная фраза обязательна только у утверждений (`source_span`) и у роли ИИ (`ai_role_span`); у полей PICO, эксперимента,
типа гипотезы и сути одной фразой её нет, и код их с текстом не сверяет (метка «без опоры»).

| Поле | Что | Основа | Заполнено |
|---|---|---|---|
| `hypothesis_type` | вмешательство / механизм / биомаркер / наблюдение | своя | 80/80 (79 — вмешательство) |
| `claim_plain` | суть одной фразой | — | 80/80 |
| `pico.population` | вид, линия, пол, возраст на старте | PICO | возраст 51/80, пол 6/80 |
| `pico.intervention` | тип, название, режим, путь | PICO | режим 76/80 |
| `pico.comparator` | тип и название контроля | PICO | 64/80 |
| `pico.outcome` | класс конечной точки (продолжительность жизни / здоровье / биомаркер / болезнь / механизм), показатель | PICO | 78/80 |
| `claims[]` | субъект — отношение (18, закрытый список, общий с графом знаний) — объект | BEL, Biolink (форма тройки) | 208 утверждений, 2.6 на карточку |
| `claims[].qualifiers` | вид, линия, пол, ткань, доза, возраст, контроль, направление, показатель | Biolink (квалификаторы), AOP (область применимости) | направление 37/208, доза 2/208 |
| `claims[].link` | доставка → мишень → путь → эффект → исход | «три опоры» Pfizer, AOP | механизм есть в 21/80 карточек |
| `claims[].role` | посылка / механизм / аналог / исход / перенос | своя (до v3) | дублирует `link`, см. раздел 5 |
| `claims[].object.hallmark` | признак старения из 12 (López-Otín 2023) | — | 16/208 |
| `claims[].source_span` | дословная фраза | BEL Evidence, Biolink supporting_text | 208/208 (обязательна) |
| `edges[]` | требует / поддерживает, если верно / аналог / противоречит | своя | 31/80 |
| `decisive_experiment` | система, дизайн, контроль, плановая выборка, первичный исход, длительность (у реестров — из строк, собранных кодом, раздел 2.2) | PICO, SPIRIT (поля реестра) | дизайн 55/80, выборка 16/80 (до полей реестра) |
| `declared_alternatives` | конкуренты, названные или отвергнутые автором | strong inference | 1/80 |
| `declared_novelty` | новизна по словам автора | — | 13/80 |
| `declared_decision_criteria` | что опровергнет гипотезу | strong inference, предрегистрация | 0/80 |
| `risks` | риски по словам автора | — | 5/80 |
| `ai_role` + `ai_role_span` | нет / анализ / в цикле эксперимента / ИИ — вмешательство | — | 3/80 не «нет» |

### 2.2 Из полей реестра и по правилу кода

**Как поля реестра попадают в карточку.** Код (`scripts/benchmark_run.build_texts`) собирает текст гипотезы из полей
ClinicalTrials.gov строками «Поле: значение»; LLM-нормализатор читает этот текст, как любой другой. Отдельных полей карточки
код из реестра не заполняет, кроме двух запасных правил ниже. Поэтому у полей эксперимента метка — «из текста», а текст
частично собран кодом из полей реестра.

| Строка текста | Из каких полей реестра | Во что превращается в карточке |
|---|---|---|
| `Title` | официальное (иначе краткое) название | `claim_plain`, утверждения |
| `Conditions` | состояния, через «;» | `pico.population.label` |
| `Interventions` | каждое вмешательство: название (тип): описание | `pico.intervention[]` |
| `Summary`, `Description` | краткое и подробное описание (до 3000 знаков каждое) | утверждения, механизм |
| `Design` | рандомизация, модель (параллельные группы, перекрёстная…), маскирование (кто замаскирован), цель — **одной строкой через запятую** | `decisive_experiment.design` (одно значение: rct / single_arm / …); маскирование и модель **отдельного поля в карточке не имеют** — их читает только судья альтернатив по тексту |
| `Arms` | каждая группа: название (тип): описание, через «;» | `decisive_experiment.control` (одно значение: placebo / active / usual_care / none) |
| `Planned enrollment` | плановая выборка, только пока она плановая | `decisive_experiment.n_planned` |
| `Primary outcomes` | каждый исход (срок), через «;» | `decisive_experiment.primary_outcome` (строкой), утверждение-исход |

**Правила кода** (`normalizer.registry_defaults`, `normalize_union`):

| Что | Правило |
|---|---|
| `pico.outcome.endpoint` | если нормализатор оставил «неизвестно» — по отношению утверждения-исхода |
| `pico.population` | если нормализатор оставил «неизвестно» — строка `Conditions`, вид — человек |
| `ai_role` | если фразы нет в тексте дословно — «нет» |
| `inherited_from_pico` | вид и линия переходят из PICO в утверждения о самом вмешательстве |
| объединение двух разборов | утверждения обоих разборов с дословной опорой; поле эксперимента или популяции, неизвестное в первом, берётся из второго |
| устойчивость карточки | доля общих утверждений двух разборов |
| идентификаторы сущностей (ChEBI, HGNC, NCBITaxon) | разрешаются позже, не везде |

### 2.3 Добавлено LLM (не из текста)

| Поле | Когда | Основа | Проверено |
|---|---|---|---|
| альтернативы (до 5, перебор 7 видов конкурентов) | после первого поиска и чтения | strong inference (Platt 1964) | Argon добавляет подкреплённого конкурента в 78% испытаний |
| d — что эксперимент делает с альтернативой | по тексту реестра на T | strong inference | κ 0.35 с Argon (30 испытаний) |
| клиничность конечной точки | две семьи моделей, иначе «неизвестно» | BEST (FDA–NIH) | согласие двух семей κ 0.93 (не эталон) |

### 2.4 Вычислено (проверенный слой)

Записи из статей (этап 4) → вес записи (GRADE) → S звена → баланс, покрытие → новизна N → I → размах W →
реализуемость → баллы профилей (ASPID / SMAA). Формулы — мануал, разделы 5–8.

### 2.5 Дубли (одно и то же в нескольких полях)

Посчитано на тех же 80 карточках.

| Что | Где записано | Что видно |
|---|---|---|
| место утверждения в цепочке | `role` (посылка / механизм / исход / аналог) и `link` (доставка … исход) | 65 утверждений: роль «посылка», звено «исход»; 21 — роль «исход» без звена; v3 читает только `link` |
| контроль | `pico.comparator.type` (7 значений), `decisive_experiment.control` (4 других значения), квалификатор `comparator` в 53 утверждениях | два словаря на одно понятие: placebo ↔ placebo, standard_care ↔ usual_care, untreated ↔ none / usual_care, other ↔ active |
| исход | `pico.outcome.metric`, `decisive_experiment.endpoint`, `decisive_experiment.primary_outcome`, объект и показатель утверждения-исхода | в регистровых карточках обычно одна и та же строка трижды |
| уровень конечной точки | `pico.outcome.endpoint` (продолжительность жизни / здоровье / биомаркер / болезнь / механизм) и клиничность по BEST (биомаркер < самоотчёт < функция < событие) | две шкалы на один вопрос; первая — от метода v1 (мыши, продолжительность жизни) |
| срок | `pico.time` (свободный текст) и `decisive_experiment.duration_class` (недели / месяцы / годы) | второе выводится из первого |
| порядок цепочки | `edges` «требует» (35 из 46 рёбер) и тип звена | порядок уже задан типом звена; рёбра нужны только для ветвления |
| аналог | `role: analog` и ребро `analog_of` | 5 и 4 случая |

## 2.6 Ядро и справочное (шаблон v13, 2026-11-12)

**Ядро** — читает оценка. **Справочное** — извлекается и хранится, оценку не меняет, доступно эволюции и отчёту.
**Слой после поиска** — альтернативы, d, клиничность, записи и всё вычисленное.

| Ядро | Происхождение | На что влияет |
|---|---|---|
| популяция | из текста, с опорой | запрос по точной популяции; контекст записей |
| вмешательства | из текста, с опорой | запросы; совпадение вмешательства; готовность |
| фон (то, что получают все группы) | из текста, с опорой | не попадает в запросы и в «вмешательство» |
| контроль (один словарь) | из текста, с опорой | отчёт; контроль эксперимента — кодом из него |
| исход гипотезы (показатель, направление) | из текста, с опорой | утверждение-исход |
| ожидаемый эффект | из текста, с опорой, или «неизвестно» | мощность эксперимента; проверка обещанного (при исходе) |
| утверждения: звено, главный исход, как сказано | из текста, с опорой | всё: поиск, чтение, S, баланс, новизна, W |
| эксперимент: дизайн, n, первичные исходы, длительность | из текста, с опорой + поля реестра | реализуемость; клиничность конечной точки |

| Справочное | Происхождение | Зачем |
|---|---|---|
| поля дизайна реестра (рандомизация, модель, маскирование, цель, группы с типами) | код из реестра | правило d кодом (backlog); эволюция |
| уровень звена (молекула … организм) | LLM | W кодом — после проверки по Argon |
| признак старения | LLM | размах механизма (пока влияет на W) |
| ссылки автора (PMID, DOI) | код из текста | затравка поиска; «утверждение автора» против «найдено» |
| идентификаторы (MeSH, ChEBI, HGNC) | код (следующий шаг) | синонимы в поиске и в счёте по отсутствию |
| роль ИИ: заявленная / правдоподобная | из текста с опорой / LLM двух семей | профиль «Финансирование» |
| тип гипотезы, суть одной фразой, заявленное автором (альтернативы, новизна, критерии, риски) | LLM | отчёт; генерация |
| класс длительности, контроль эксперимента | код | реализуемость |
| устойчивость карточки | код | доверие к карточке |

Отложено: «состояние популяции» как тип звена (разбор и определение — в эталоне Argon тип размыт); необходимость звена
(AOP) — backlog.

## 3. Основы со схемы: что похоже, чем отличаемся

Примеры: **H49** (NCT07726758: приседания 12 недель у пожилых с пре-саркопенией против обычного ухода, РКИ, 80 человек;
первичные исходы SPPB и состав тела) и иллюстративная молекулярная гипотеза **R** («рапамицин с 20 месяцев подавляет
mTORC1 в печени и продлевает медианную продолжительность жизни мышей UM-HET3»; написана для примера, не из пула).

Как сверено: PICO, «три опоры», GRADE, strong inference, предрегистрация, TRIPOD — по библиографическим записям и аннотациям
PubMed (2026-11-12); AOP — по аннотациям Ankley 2010 (PMID 20821501), Villeneuve 2014 (PMID 25466378) и применению
руководства ОЭСР (PMID 35143163); BEL — по исходникам и примерам PyBEL 0.15.5; Biolink — по `biolink-model.yaml` версии
4.4.6; SciFact и evidence inference — по репозиториям наборов. BEST, SMAA, АСПИД, Cochrane Handbook — по тексту, на который
ссылается схема; [проверить по первоисточнику] перед статьёй.

### Этап 2. Карточка

| Основа | Что это | Пример | Похоже | Отличаемся |
|---|---|---|---|---|
| **PICO** (Richardson et al., ACP J Club 1995) | вопрос клинического исследования: популяция, вмешательство, сравнение, исход | H49: P — пожилые с пре-саркопенией; I — приседания 12 нед.; C — обычный уход; O — SPPB, InBody | блок `pico` — скелет карточки | у PICO одна стрелка I → O; нет механизма, альтернатив, дословной опоры; нет оценки |
| **«Три опоры» Pfizer** (Morgan et al., Drug Discov Today 2012): экспозиция в месте действия, связывание с мишенью, функциональная фармакологическая активность; в 43% из 44 программ фазы II нельзя было сказать, проверен ли механизм | R: рапамицин в печени (экспозиция) → связывание FKBP12–mTOR (мишень) → снижение pS6 (активность) → продолжительность жизни | типы звеньев «доставка → мишень → путь/эффект» | Pfizer — чек-лист для решения о фазе II по данным; у нас — типы утверждений текста, сила по литературе. Для невещества «доставка» = вмешательство выполнено (приверженность) — наша адаптация |
| **AOP** (Ankley et al. 2010; руководство ОЭСР): начальное молекулярное событие → ключевые события → неблагоприятный исход; на связь — вес доказательств (правдоподобность, эмпирическая поддержка), на событие — необходимость | H49 в AOP: нагрузка на мышцу → синтез мышечного белка ↑ → сила разгибателей ↑ → SPPB ↑ | цепочка шагов с силой каждой связи (S) | (1) AOP не привязан к веществу (принцип 1), у нас субъект — вмешательство: в карточке H49 у всех пяти утверждений субъект «squat exercise», цепочка задана типом звена, а не тем, что объект одного шага — субъект следующего; (2) AOP строят эксперты по всей литературе, у нас — только то, что сказано в тексте; (3) вес в AOP качественный (Брэдфорд Хилл), у нас S числом из записей; (4) **необходимости звена** (блокада шага → исход не наступает) у нас нет; (5) AOP соединяются в сети с общими событиями, у нас цепочки отдельны |
| **BEL** (OpenBEL; PyBEL): утверждение «функция(сущность) отношение функция(сущность)» с аннотациями `SET Citation`, `SET Evidence`, `SET Species` | R: `SET Citation = {"PubMed", "…"}` `SET Species = 10090` `a(CHEBI:sirolimus) decreases act(p(MGI:Mtor))` | тройка + контекст + ссылка + дословная фраза; закрытые отношения; есть «нет эффекта» (`causesNoChange`) | BEL записывает **то, что сказала статья** (наш слой записей), а не гипотезу; идентификаторы обязательны; различает прямое и косвенное действие (`directlyDecreases`); у утверждения нет веса и дизайна |
| **Biolink** (версия 4.4.6): ассоциация subject — predicate (246 в иерархии) — object + квалификаторы + происхождение | R: subject CHEBI:sirolimus, predicate `affects`, qualified_predicate `causes`, object MGI:Mtor, `object_aspect_qualifier: activity`, `object_direction_qualifier: decreased`, `species_context_qualifier: NCBITaxon:10090`, `knowledge_level: prediction`, `agent_type: computational_model` | наши квалификаторы ≈ `species_context` / `anatomical_context`; «показатель» ≈ `object_aspect`; направление (v11) ≈ `object_direction`; цитата ≈ `supporting_text`; **`knowledge_level: prediction` против `knowledge_assertion` — то же разделение, что наши два слоя** | словарь у нас 18 отношений; аспекты Biolink молекулярные («приседания → SPPB» ложится плохо); нет цепочки как объекта, эксперимента, альтернатив; число уверенности без правила |

### Этап 3–4. Поиск и чтение

| Основа | Что это | Пример | Похоже | Отличаемся |
|---|---|---|---|---|
| **Сбор данных Cochrane** (Li, Higgins, Deeks; Handbook, гл. 5) | форма извлечения: участники, вмешательства, исходы, дизайн, результаты; извлекают двое независимо | статья об РКИ силовых тренировок: n, группы, исход SPPB, результат между группами | поля записи: дизайн, n, сравнение, фраза эффекта, совпадение вмешательства | один читатель (LLM) + проверки кода вместо двух людей; двойной разбор у нас только для карточки; извлекаем из аннотации, не из полного текста |
| **Evidence inference** (Lehman et al., NAACL 2019) | запрос (вмешательство, контроль, исход) → значимо больше / меньше / нет различия + опора в тексте | «приседания vs обычный уход, SPPB» → «значимо больше» + предложение из результатов | сторона записи = вывод по I/C/O с опорой; ноль → «против» (правило чтения 2) | у них запрос дан, у нас его строит звено; мы добавляем вес (дизайн, n, контекст); отбор статей — наш поиск |
| **SciFact** (Wadden et al., EMNLP 2020) | утверждение + аннотации → поддерживает / опровергает / нет данных + предложения-обоснования | «рапамицин продлевает жизнь мышей» + аннотация ITP → поддерживает | то же решение «за / против / нет» с цитатой на ~20 аннотаций за вызов | у нас утверждение — звено с квалификаторами (вид, популяция), совпадение контекста меняет вес; одна цитата, а не набор предложений |

## 4. Чего нет ни у одной основы и есть у нас

- Гипотеза как объект с двумя слоями: заявлено (с дословной фразой) отдельно от найденного.
- Эксперимент оценивается таким, как заявлен, против подкреплённых до T альтернатив (I).
- Новизна по самой близкой записи до T и счёту PubMed по отсутствию.
- Версии гипотезы с правилами раздела 11 и разложением прироста на «гипотезу» и «эксперимент».
