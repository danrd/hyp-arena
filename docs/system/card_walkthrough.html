Разбор карточки H86 и H49

Приложение к мануалу этапа «Карточка» (docs/system/card.md). Каждая карточка построена нормализатором с шаблоном v15: два независимых разбора текста, затем объединение. Разбор идёт от исхода назад: главный фактор, цепочка от него, посылки о проблеме отдельно. Для каждого поля: главное значение, его подполя, как они получены из текста, откуда (метка происхождения) и что в оценке поле читает. Спорное вынесено в сноски под карточкой. Нажмите на поле или утверждение, и в тексте слева выделится фраза, на которой оно держится.

Подполя заданы схемой карточки и одинаковы для любой гипотезы: у популяции — вид, возраст, пол (и штамм для животных); у вмешательства — тип, доза или режим, путь введения (для упражнений и процедур путь не показывается). «Не сказано» — значения в тексте нет, и карточка его не додумывает.

из текста, с опорой LLM записала значение и дословную фразу, код проверил фразу из полей реестра код разобрал строки Design, Arms, Planned enrollment правилом кода выведено из других полей по фиксированному правилу LLM, без опоры суждение модели по тексту, фразы нет не сказано в тексте этого нет

Карточки и журнал вызовов: longevity-kg/hypothesis_sources/calibration/walkthrough_H86/card_v14.json, …/prospective/walkthrough_H49/card_v14.json. Тексты реестра собраны из текущей записи ClinicalTrials.gov 2026-11-13. Правила кода — hyparena/card/normalizer.py.

Карточка — только то, что сказано в тексте. Найденное потом (статьи, сила звеньев, альтернативы, баллы) сюда не входит и разбирается на следующих этапах со своими мануалами.
