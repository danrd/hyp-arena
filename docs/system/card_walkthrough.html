Разбор карточки H86 и H49

Приложение к мануалу этапа «Карточка» (docs/system/card.md). Каждая карточка построена текущим нормализатором (два независимых разбора, объединение) по тексту записи реестра, как его собирает код. Для каждого поля: значение, как оно получено из данных, откуда (метка происхождения) и что в оценке его читает. Спорное по полю вынесено в сноски под карточкой. Нажмите на поле или утверждение, и в тексте слева выделится фраза, на которой оно держится.

из текста, с опорой LLM записала значение и дословную фразу, код проверил фразу из полей реестра код разобрал строки Design, Arms, Planned enrollment правилом кода выведено из других полей по фиксированному правилу LLM, без опоры суждение модели по тексту, фразы нет пусто в тексте этого нет

Данные: longevity-kg/hypothesis_sources/calibration/walkthrough_H86/card_v14.json, …/prospective/walkthrough_H49/card_v14.json (карточка, оба разбора, журнал вызовов). Тексты собраны scripts/benchmark_run.build_texts из текущей записи ClinicalTrials.gov 2026-11-13. Правила кода — hyparena/card/normalizer.py (derive_roles, v13_code_fields, registry_design, duration_class, dedupe_claims).

Карточка — только то, что сказано в тексте. Найденное потом (статьи, сила звеньев, альтернативы, баллы) сюда не входит и разбирается на следующих этапах со своими мануалами.
