# Журнал изменений метода

Здесь — как метод пришёл к текущим правилам: что и когда менялось, почему, на каких проверках это основано. Мануалы
([сводный](../method-v3-manual.md), [карточка](card.md)) описывают только текущую трактовку и ссылаются сюда. Версии до v3.7
(v3.0–v3.6, таблицы весов, прежние примеры) — в [`archive/method-history.md`](../../archive/docs/method-history.md).

Записи внутри раздела — от новых к старым. Цитаты из прежнего текста мануала оставлены на английском, как были.

## Общее: версии правил

- **v3.10 (2026-11-14).** Все шаги механизма — одно место баланса, по самому слабому шагу с данными
  ([`specs/card/merge-steps-2026-11-14.yaml`](../../specs/card/merge-steps-2026-11-14.yaml)): R3 0.594 против 0.584, сдвинулась 1 из 59
  проспективных единиц. Причины: тонкие типы шагов в оценке почти ничего не меняют и хуже всего согласуются (на 22 трудных
  текстах мишень и клеточный процесс не взяла и сильная модель; у эталона Argon свои нарушения определений); отдельные
  места позволяли поднимать баланс добавленным известным шагом. Нормализатор v16: один класс «шаг механизма», не больше 4
  шагов; посылки не ищутся. Разобранный пример v3.7–v3.9 — в `archive/method-history.md`.
- **2026-11-14, учёт ресурсов** (сводный мануал, раздел 15): время вызова в журнале, таблица цен `configs/prices.yaml`,
  сводка по этапам `hyparena/reports/usage.py`, лимит в USD; модель, пишущая отчёт по мануалу, свои ресурсы не сообщает.
- **v3.9 (2026-11-11).** Уровень новизны «новый механизм известного эффекта»; карточка — объединение двух разборов; вес
  метаанализа по уверенности GRADE; дизайн записи по типам публикаций PubMed. Проверка
  ([`specs/reading/meta-and-nulls-2026-11-09.yaml`](../../specs/reading/meta-and-nulls-2026-11-09.yaml)): R2 0.697 и R3 0.582 против 0.702 и
  0.593 — в пределах правила 0.03.
- **v3.8 (2026-11-11).** Третий уровень совпадения вмешательства — «только та же категория», считается смежным (правило
  чтения 1).
- **v3.7 (2026-11-09).** Вес записи v3.6 по доменам GRADE; сила звена как сумма логарифмов отношения правдоподобия; баланс
  доказательств по звеньям с данными; профили ASPID; правила, которые сохраняет каждая улучшенная версия.
- **2026-11-13.** Сводный мануал и мануал карточки очищены от истории и обоснований; они перенесены сюда.

  половина иначе — лучше, чем убрать множитель (снижало R2 и R3), и лучше, чем считать «не указан» полным (R2 0.693, R3 0.580,
  R4 0.065 против 0.712, 0.595, 0.099). «Не указан» считается малым: при сомнении — нижний уровень.
- **Сравнение, два уровня.** Между группами или нет; различие «внутри группы / нет сравнения» ничего не добавило.
- **Контекст, два уровня.** Метка «класс» ридера согласовалась с ручной проверкой при κ 0.38 и с внешним читателем при κ 0.10
  (ридер ставит «класс» примерно вдвое чаще), а штраф 1/3 снижал R2; пока ридер не перепрогнан с правилом v10, класс не
  штрафуется. Смежное — один раз, 1/2, только по уточнениям, которые утверждение называет.
- **Не принято:** риск смещения по словам аннотации (65% аннотаций испытаний ничего не говорят о маскировании; правило о
  субъективных исходах внешний читатель подтвердил на 13 из 29 записей) — вернуть, когда ридер будет извлекать маскирование;
  штраф за результат только в подгруппе (нарушил R3).
- **Свёртка.** Сумма логарифмов отношения правдоподобия обошла среднее Beta по R2 (+0.023, единственный парный интервал выше
  0) и по R3; правило «лучшая запись» не прошло R3; счёт статей без весов был ниже всех по R2 (0.653), но выше всех по R3
  (0.622) — против исходов испытаний веса ничего не добавляют к счёту.
- **Итог v3.6 против v3.5:** R2 0.702 против 0.657 (парный 95% интервал +0.009 … +0.091), R3 0.593 против 0.608, R4 τ-b 0.099

  (R2 около ±0.09): выбор опирается на GRADE и ясность, данные показывают, что он не хуже.
