  jinja2 openai -e "toolkit[llm-kit]"`; база вопросов костяка: `python -B -m tools.skeleton.backfill --method-root ../hyp-arena`
  (в `longevity-kg`).
- Полная сборка отчёта здесь не проходит: правилу «одобренное вещество» нужен PubChem (закрыт, кеша соединений нет). Отчёт
  обновлялся так: числа из уже собранного HTML (`const DATA = …`) подставляются в новый шаблон; на домашнем ПК
  `python -m hyparena.report_v2 prospective` собирает с нуля.
- Проверка вёрстки: Tailwind с CDN здесь недоступен — CSS собирается локально (`npm i tailwindcss@3.4.17`, `npx tailwindcss
  --content шаблон`) и подставляется в Playwright; схема draw.io рендерится через npm `mxgraph@4.2.2`.
