# Реестр бенчмарков по этапам

Решение руководства и пользователя (2026-11-12): основной вектор — полноценный бенчмарк для каждого этапа системы, хотя бы
через сравнение с эталоном, как для чтения. Эталоны размечает Argon (внешний читатель вслепую), людей-разметчиков нет;
где возможно — готовые публичные наборы и эталоны, которые код строит сам из курируемых баз.

**Что считается бенчмарком этапа:** зафиксированный набор входов (список и хеш), эталон для каждого входа, метрика и порог,
записанные до прогона (`specs/`), бейзлайн «LLM напрямую» на тех же входах и том же эталоне, повторяемый запуск одной
командой, число с интервалом. Этапы нумеруются по схеме [`../system/flow_base.png`](../system/flow_base.png).

Статус: **есть** — все части выше на месте; **частично** — есть эталон и число, но набор мал, не зафиксирован или нет
бейзлайна; **нет**.

## Что строить по этапам

**2. Карточка.** Пакет Argon 17 собран 2026-11-12 (`scripts/pack17_card.py`, ответ ждём). Набор 60 текстов: 20 реестров с названной причиной эффекта, 20 без неё, 20 гипотез с выписанным механизмом
(из спецификации `mechanism-chain-comparison`, тексты те же). Эталон — пакет Argon: поля PICO, звенья с дословной опорой,
тип каждого звена, заявленный эксперимент. Метрики: точность и полнота звеньев, κ типов звеньев, точность полей; устойчивость
— совпадение двух разборов и двух семей. Бейзлайн — LLM по той же схеме. Следить, чтобы эталон не «додумывал»: только то,
что текст говорит сам.

**3. Поиск.** Добавить эталон, который код строит сам: известные факты DrugAge и Open Genes с PMID статьи (тысячи пар, без
разметки) — найдена ли статья факта до её даты; и прежние испытания из ссылок реестров для новизны (этап 6). Метрика recall@20.
Бейзлайн — ссылки, которые LLM даёт без поиска: существуют ли, до T ли, совпадают ли с эталоном.

**4. Чтение.** Зафиксировать пакеты 9, 13, 15 как набор (хеш), добавить публичные наборы: evidence inference (Lehman et al.,
NAACL 2019; запросы «вмешательство, контроль, исход → значимо больше / меньше / нет различия» с опорой в тексте) и SciFact
(Wadden et al., EMNLP 2020; «поддерживает / опровергает» с предложениями-обоснованиями) — проверить лицензии; известные
факты против изменённых (`specs/known-facts-test-2026-11-09.yaml`). Метрики: полнота и точность находок, точность стороны,
доля дословных цитат. Бейзлайн — LLM на тех же текстах (утечка не мешает: задача — извлечь из данного текста).

**5. Сводка доказательств.** Зафиксировать R2 (поздние РКИ того же звена) как набор с хешем; пакет Argon на 150–200 пар
находок (R4 сейчас — 80 пар, τ 0.10 — слабо различает). Бейзлайн — LLM упорядочивает те же пары.

**6. Новизна.** Эталон кодом: если среди ссылок реестра (BACKGROUND, до регистрации) есть испытание того же вмешательства и
исхода, уровень не может быть выше «нового контекста». Плюс пакет Argon побольше (сейчас 37): ближайшая прежняя работа с
PMID и уровень. Метрики: взвешенная κ уровня, доля завышений. Бейзлайн — LLM называет ближайшую прежнюю работу.

**7. Эксперимент и альтернативы.** Пакет Argon на 100 испытаний: конкуренты с опорой и что с каждым делает дизайн по тексту
реестра (с полями дизайна). Метрики: κ «отсекает / ослабляет / не различает», полнота конкурентов. Бейзлайн — тот же вопрос LLM.

**8. Прочие показатели.** Клиничность — эталон Argon по таксономии исходов COMET (Dodd et al., 2018) на 100 испытаниях;
реализуемость — Argon оценивает по той же формуле из текста (проверка извлечения частей, а не формулы); хайп — после
определения показателя.

**9. Ранжирование.** «Доказательность» — исходы испытаний (как сейчас) и баланс Argon по испытаниям; «Финансирование» —
что реально получило деньги (решения VitaDAO по заявкам, сделки) — после пересмотра профиля; «Фронтир» — пары гипотез,
которые Argon упорядочивает по новизне.

**10. Улучшения и версии.** Пары «исходная — версия» вслепую для Argon: лучше ли версия как гипотеза, отдельно — как
эксперимент; доля нарушений восьми правил.

**11. Сквозная проверка.** Ждёт исходов; закрепление оценок текущего метода — в backlog.

## Порядок

1. Чтение (готовые наборы и пакеты Argon уже есть — зафиксировать и добавить бейзлайн).
2. Поиск и новизна (эталоны строит код, бесплатно).
3. Карточка (пакет Argon на 60 текстов; совпадает с проверкой разложения механизма).
4. Альтернативы, клиничность, сводка, версии — пакетами Argon.

Каждый бенчмарк — спецификация в `specs/` (набор, эталон, метрика и порог до прогона), команда запуска и запись результата в
этот реестр.
