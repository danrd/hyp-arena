## 2. Пул DrugAge на 2015 год и расхождение профилей

- **Состав.** `data/calibration/drugage_2015.json`; T = 2015-12-31; источник DrugAge (дампы HAGR, даты публикаций по PMID); четыре страты по числу работ до T: **deep** (две и более работы на мышах), **shallow** (одна), **other_species** (записи только по другим видам), **none** (до T ничего, первая запись позже). Соединения разрешены по таблице соединений; названия, не сводимые к одному соединению, исключены. Детерминированная выборка по хэшу названия. Метки не нужны.
- **Карточки и проверка.** Карточки по шаблону кодом; проверка только по куративным записям DrugAge (PubMed и модели выключены, вызовов моделей ноль). Каждому соединению задана линия мышей, которой нет среди его записей, иначе доказанное становится «известным результатом» и уходит из рейтинга.
- **Выводы.** Здесь профили расходятся заметнее, чем на ITP; ведущий показатель `path_to_human`, но не монополия. Числа и разбор в `docs/rules-method.md` («Решения по калибровке внесены (2026-10-23)», «path_to_human: только безопасность…»). Код: `scripts/drugage_pool.py`; на странице пятый пример переключателя.

## 3. Решение по `informativeness` на ITP

Не считается: первый прогон был до показателя, считать значило бы вызывать модели по замороженной выборке и менять эталон. Остаётся неизвестным у всех режимов (диагностика показывает «неизвестен у всех»). Считается только в новых прогонах (`--informativeness`). `docs/rules-method.md` («Решения 2026-10-25…»), `docs/site/content/reference/aggregation/20-data.md`.

## 4. Парная проверка верификатора (зависимость от названия)

Метод: сохранённые запросы и ответы проверяющей модели на ITP 2010; три руки (сохранённый ответ, те же запросы с названиями вмешательства, заменёнными кодом, повтор без изменений для оценки шума). Результат, оговорки и чего проверка не доказывает: `docs/rules-method.md` («Парная проверка…»). Код `scripts/blind_check.py`, тесты `tests/test_blind_check.py`. Сам прогон (`runs/stage5/blind_itp2010.json`) в репозитории не лежит. Для синхронизации заметок: в `Working_Notes` (A1) маскирование названий записано как «отклонено»; теперь это выполненная диагностика, а не метод; решение «спрашивать модель, знает ли она исход» остаётся отклонённым.
