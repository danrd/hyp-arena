# Пилот общей подсказки о новизне

В каждой генерации пять гипотез. На одну модель приходится 20 гипотез, по пять на условие. В качестве исходных берём фактические задания A1 и BS1 из прогона 19 ноября. Для всех четырёх условий проводим свежую генерацию с одной темой, одной датой среза, одинаковыми параметрами модели и бюджетами поиска и вывода. При сравнении нескольких моделей формируем отдельный пул из 20 гипотез для каждой.

| Условие | Гипотез | Задание |
| --- | ---: | --- |
| A1 | 5 | Исходное задание A1 |
| BS1 | 5 | Исходное задание BS1 |
| A2 | 5 | A1 с одной фразой в общей части |
| BS2 | 5 | BS1 с той же фразой в общей части, до блока метода |

Добавляем в A2 и BS2 сразу после первого пункта общей задачи:

> When developing each hypothesis, consider how the idea differs from existing knowledge and approaches.

Отдельного поля для ответа не требуется. Текущая часть BS с карточкой и проверками сохраняется дословно. Более подробные изменения блока метода рассматриваются в отдельном эксперименте. В исходных A1 и BS1 уже есть просьба объяснить вклад относительно ближайшей работы. Она сохраняется во всех четырёх условиях. Поэтому пилот измеряет добавочный эффект ранней широкой подсказки во время формирования идеи.

## Оценка

Готовим одно досье для всех условий по общей процедуре. Присваиваем слепые ID и сравниваем все 190 уникальных пар по зафиксированной инструкции судьи v3 с одним общим вердиктом на пару. Промпты, ключ условий, баллы мануала и прежние вердикты остаются вне входа судьи.

По 25 пар в каждом из четырёх сравнений отвечают на основные вопросы:

- A1–A2 и BS1–BS2 показывают эффект добавления фразы внутри каждой ветки.
- A1–BS1 и A2–BS2 показывают, насколько различается вклад текущей части BS с общей подсказкой и без неё.

В сводке выводим общие вердикты, предпочтения и мотивировки по новизне, проверяемости и обоснованности. Сходные идеи учитываем при интерпретации побед. Выводы относятся к этому пулу. Для проверки устойчивости нужны независимые повторы генерации.
