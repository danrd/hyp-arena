# Бенчмарк v2: гипотезы из реестров испытаний

Главный тест метода. Протокол зафиксирован до прогона: [`specs/benchmark-v2.yaml`](../specs/benchmark-v2.yaml); правила
запуска — `specs/benchmark-v2-run.yaml` (пишется до первого платного вызова). Список единиц: `data/benchmark/v2_units.json`
(номера, метки, даты, флаги; текстов нет — они лежат в закрытом репозитории графа знаний). Команды: [`commands.md`](commands.md).

## Зачем

Прежние бэктесты (ITP, CITP) подавали методу голые строки вида «вещество X продлевает жизнь мышей». Так меряется сортировка
сырых идей, а не оценка аргументированной гипотезы, ради которой метод построен. Нужны гипотезы, которые написали люди до
результата, с датой, обоснованием и исходом позже. Такой материал есть в реестрах клинических испытаний: исследователь
описывает, что и зачем проверяет, до набора данных, а исход публикуется потом.

источнику — в спецификациях `specs/*-outcomes-*.yaml`.

## Метки исхода

- Метку ставит модель по документу исхода (результаты в реестре или статья) с дословной цитатой; цитата обязана быть в
  источнике. Решает зарегистрированный первичный исход и сравнение между группами.
- Перепроверено вручную 166 из 237 меток. Для 36 испытаний без опубликованного вывода, но с выложенными числами, тест
  пересчитан по данным групп; при нескольких временных точках: все значимы → положительный, ни одна → нулевой, часть → смешанный
  (смешанные в бенчмарк не входят).
- Испытания, где текст реестра явно правили после результата, помечены и идут только в анализ чувствительности; с результатом
  прямо в тексте — исключены.

## Что считается

- **Б1** — все 237 точек, рабочая пара моделей: Gemini 3.5 Flash собирает карточку, DeepSeek V4.1 Flash проверяет утверждения.
  Определяет статус теста.
- **Б2** — 98 точек, чей первый документ исхода вышел после отсечки знаний gpt-4o (2023-10-01); gpt-4o в обеих ролях. Проверяет,
  что сигнал Б1 не объясняется памятью модели.
- Каждое испытание оценивается на дату своей регистрации: литература позже этой даты отрезается (поиск по дате публикации и
  повторная проверка каждой статьи по самой ранней публичной дате).
- Мера — AUC с ничьими (балл профиля evidence_first: положительный исход против нулевого или отрицательного), p по перестановкам,
  95% бутстреп-интервал.
- В подсчёте все 237 точек. Порядок баллов: «результат уже известен» (литература до регистрации уже показала то же) — наверху;
  ранжированные — по баллу; «метод не смог оценить» — ниже; отсеянные (опровергнуты ранней литературой) — в самом низу.

| | Пройдено | Провал | Иначе |
|---|---|---|---|
| Б1 | AUC выше 0.565, p < 0.05 и нижняя граница выше 0.5 | верхняя граница ниже 0.60 | не доказано |
| Б2 | то же с порогом 0.609 | то же | то же |

Пороги взяты из мощности: при 82 положительных Б1 различает AUC около 0.60 с мощностью 80%.

## Обязательные сравнения

- **Формальная базовая линия.** Логистическая регрессия по шапке реестра (фаза, рандомизация, маскирование, размер, тип
  вмешательства, спонсор, год), оценки по 5-кратной кросс-валидации. Посчитана до прогона метода: Б1 AUC 0.543 [0.464; 0.618],
  Б2 0.494 [0.378; 0.607] — шапка почти не предсказывает исход. Метод должен быть лучше неё на парной разности.
- **Проверка на память.** Та же модель, что проверяет, получает только название испытания и называет вероятность
  положительного исхода. Если метод не отличим от этого, сигнал — припоминание.

Анализы чувствительности: без точек, правленых после результата; только перепроверенные вручную метки; без пересчитанных;
без агрегированных по нескольким точкам; только CT.gov; без «результат уже известен»; без «метод не смог оценить».

## Подготовка (2026-11-01)

- Тексты гипотез собраны кодом из полей реестра: название, вмешательство, состояние, описание, первичные исходы. Без номера
  испытания, дат, результатов и статей. Медианная длина 2900 знаков.
- Сухой прогон без вызовов моделей: на сборку карточек Б1 уходит 835 тыс. входных токенов. Объём проверки утверждений
  без реальных карточек не измерить; оценка всего прогона Б1 + Б2 — 10–16 долларов.
- Ревизия метода перед запуском: срез по дате, допуск карточек, независимость балла от состава набора, дубли между реестрами
  (не найдены), лимиты API. Найдено и исправлено: запись модели, которая фактически ответила (Google перенаправляет
  устаревший gemini-3.5-flash на 3.6). Открыто: gpt-4o не проходил приёмку ни как нормализатор, ни как проверяющий.
- Пилот на шести испытаниях CT.gov вне бенчмарка (смешанный или неопубликованный исход), чтобы найти технические ошибки,
  не подгоняя метод под оцениваемые точки.
