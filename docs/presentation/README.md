# Презентация проекта (HypArena · Open Longevity)

Актуальная версия презентации — **Версия 4 (23 ноября 2026 · метод v3.13)** с акцентом на проблематику научных гипотез, их ИИ-генерацию, анти-хак механизмы v3.13, итоги калибровки/holdout и дорожную карту.

## Файлы

- [`hyp-arena-v4-2026-11-23.pdf`](hyp-arena-v4-2026-11-23.pdf) — итоговый 20-слайдовый векторный PDF (16:9).
- [`hyp-arena-v4-2026-11-23.html`](hyp-arena-v4-2026-11-23.html) — автономный исходник слайдов (открывается в любом браузере с навигацией стрелками `←` / `→` и кнопкой печати в PDF).
- [`build_pdf.py`](build_pdf.py) — скрипт пересборки PDF из HTML через локальный headless Chrome / Edge:

```sh
python docs/presentation/build_pdf.py
```

## Что обновлено относительно Версии 3 (3 ноября 2026)

1. **Новый сквозной акцент — проблематика гипотез и их генерации (слайды 2–6):** конфликты осей качества, перекосы слепого LLM-судьи v3 (`testability` 50% vs `novelty` 3.2%), шесть системных сбоев ИИ-гипотез из пилотов `10x10-20` и `Sol-20`, разбор «налога на новизну» (`A1/BS1` vs `A2/BS2`) и новая архитектура промптов `A3` / `BS3`.
2. **Актуализация метода до `v3.13` (слайды 8–12):** переход от произведения правдоподобий к знаковому балансу доказательств с обязательными звеньями (`required_for_balance`), `paper_outcomes/v2`, `N = None` внизу шкалы, `endpoint_clinical` по системе эксперимента, багфикс чек-листа клеток, две ветки проверки готовности (`ChEMBL + CT.gov <= T` и Канал Б `implementation_readiness/v1`), разложение реализуемости в HTML-отчёте и три профиля АСПИД.
3. **Актуальные данные, калибровка и дорожная карта (слайды 13–20):** 4 уровня валидации, результаты dev (`Sol-20`) и holdout (`10x10-20`, `pack_26`), честно отбракованные варианты, сквозной прогон на 73 калибровочных испытаниях (`R3 = 0.578`, покрытие `92%`), замороженный проспективный пул (60 испытаний), парный ретро-бенчмарк (237 испытаний), граф знаний (2313 статей, 6263 наблюдения, 1723 гипотезы) и обновлённый календарь публикаций на 2027 год.
