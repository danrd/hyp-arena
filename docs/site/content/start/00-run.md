## Что получится {#run-what}

Вы загружаете свои гипотезы и получаете рейтинг и карточки с цитатами из статей. Результат открывается на главной странице сайта, там же можно скачать таблицу. Всё считается на вашем компьютере.

## Что понадобится {#run-need}

- Python 3.11 или новее.
- Ключ хотя бы одного провайдера языковых моделей: OpenAI, Anthropic или Google. Это платный доступ к модели, обычно его выдают в личном кабинете провайдера.
- Немного времени и денег. На одну гипотезу уходит несколько вызовов модели, на десяток гипотез — несколько минут (в примере на сайте 37 вызовов на десять гипотез). Сколько это стоит, зависит от провайдера и модели. Расход можно ограничить параметром `--max-calls`: когда лимит вызовов кончится, запуск остановится.

## Шаг 1. Установить {#run-install}

Откройте терминал и выполните:

```
git clone https://github.com/danrd/hyp-arena
cd hyp-arena
pip install -e .
```

**Что вы увидите, если всё хорошо.** Последняя строка вывода начинается со слов «Successfully installed».

## Шаг 2. Задать ключ {#run-key}

Укажите ключ хотя бы одного провайдера и разрешите платные вызовы. Подойдёт любой из ключей; провайдеры без ключа пропускаются, а если ключей несколько, проверку делают разные модели.

```
export OPENAI_API_KEY=...      # OpenAI
export ANTHROPIC_API_KEY=...   # Anthropic (Claude)
export GEMINI_API_KEY=...      # Google (Gemini)
export ALLOW_PAID=1
```

Команды написаны для bash и zsh. В PowerShell на Windows то же самое выглядит так: `$env:OPENAI_API_KEY="..."`. Переменные действуют только в том окне терминала, где вы их задали.

Модели и ключи описаны в файле `configs/v2-direct.yaml`. В нём можно включить DeepSeek, xAI и Mistral (`DEEPSEEK_API_KEY`, `XAI_API_KEY`, `MISTRAL_API_KEY`) или указать `base_url` любого сервиса, совместимого с OpenAI. Агрегаторы: CometAPI (ключ `COMET_API_KEY`) и бесплатные модели OpenRouter (`configs/models.yaml`, ключ `OPENROUTER_API_KEY`). Для CometAPI основная конфигурация — `configs/v2-flash.yaml`: карточки разбирает Gemini 3.5 Flash через собственный вход Google (провайдер `gemini_native`) с выключенными скрытыми рассуждениями, проверку делает DeepSeek V4.1 Flash. В `configs/v2.yaml` Gemini идёт через вход, совместимый с OpenAI: там CometAPI не даёт выключить скрытые рассуждения и берёт за них плату как за ответ, поэтому разбор карточек выходит примерно втрое дороже. Google отмечает `gemini-3.5-flash` как устаревшую и перенаправляет запросы к ней на `gemini-3.6-flash`. Качество у бесплатных моделей ниже; читайте предупреждение в разделе «Конфиденциальность».

**Что вы увидите, если всё хорошо.** Ничего: команды `export` молчат. Проверить можно так: `echo ${OPENAI_API_KEY:+ключ задан}` выведет «ключ задан».

## Шаг 3. Записать гипотезы {#run-hypotheses}

Создайте текстовый файл `мои_гипотезы.txt`. Пишите гипотезы по одной на абзац (между абзацами пустая строка) или нумерованным списком:

```
1. Метформин, который мыши получают с середины жизни, продлевает их жизнь.

2. Рапамицин улучшает здоровую продолжительность жизни у пожилых людей.
```

Лучше всего работают гипотезы о вмешательствах и механизмах старения: что, кому, в какой дозе и с каким исходом.

**Что вы увидите, если всё хорошо.** Файл открывается в обычном текстовом редакторе, и в нём читаются ваши гипотезы. Отдельной проверки на этом шаге нет, формат проверится при запуске.

## Шаг 4. Запустить проверку и рейтинг {#run-go}

```
python -m hyparena.card.pipeline --paste мои_гипотезы.txt \
    --config configs/v2-direct.yaml --max-calls 200 --out runs/mine.v2.json
```

**Что вы увидите, если всё хорошо.** Программа по ходу работы пишет, на каком этапе она находится. В конце выводит по строке на каждую гипотезу с её исходом («ranked» значит «в рейтинге»), рейтинг по каждому профилю и итог: число вызовов, время и имя файла `runs/mine.v2.json`.

## Шаг 5. Собрать файл для страницы {#run-export}

```
python -m hyparena.site export --v2 runs/mine.v2.json \
    --title "Мои гипотезы" --out runs/site/mine.json
```

Затем откройте главную страницу сайта, нажмите «Открыть свой прогон» и выберите файл `runs/site/mine.json`. Файл можно и перетащить на страницу.

Чтобы рядом был рейтинг Elo (турнир, в котором модели спорят о гипотезах), прогоните те же тексты турниром командой `python -m hyparena.live run --import-file …` и добавьте в команду выше параметры `--elo` и `--pool`.

**Что вы увидите, если всё хорошо.** Команда печатает путь к созданному файлу. На главной странице вместо примера появляются ваши гипотезы: метка «Пример» исчезает, в полосе стоит название вашего прогона, а во вкладке «Сравнение» — ваш рейтинг.

## Конфиденциальность {#run-privacy}

Ваши гипотезы и ключ не уходят никуда, кроме выбранного провайдера моделей, PubMed и открытых баз. Страница результат никуда не отправляет: файл читается в вашем браузере.

Бесплатные эндпоинты OpenRouter могут сохранять запросы, поэтому неопубликованные гипотезы через них не отправляйте.

## Если что-то не работает {#run-trouble}

**Запуск пишет «No API key is set for any model of this config».** Ключ не задан в этом окне терминала. Выполните шаг 2 в том же окне, где запускаете программу. Если ключ задан, но провайдер отвечает ошибкой доступа, проверьте сам ключ и то, что у него есть доступ к модели из `configs/v2-direct.yaml`.

**Запуск пишет «is a paid model; set ALLOW_PAID=1 to use it».** Платные вызовы по умолчанию выключены. Выполните `export ALLOW_PAID=1`.

**Запуск остановился с сообщением «call cap of … reached».** Закончился лимит вызовов из параметра `--max-calls`. Увеличьте его (по умолчанию 400) и запустите снова; чем больше гипотез, тем больше вызовов нужно.

**Программа прочитала весь файл как одну гипотезу.** Гипотезы разделяются пустой строкой или нумерацией «1.», «2)»; нумерация засчитывается, если пунктов не меньше двух. Если всё написано подряд, строка за строкой, разделите их пустыми строками.

**Страница пишет «Это не файл страницы».** Вы выбрали не тот файл. Нужен результат шага 5 (`runs/site/mine.json`), а не файл `runs/mine.v2.json` из шага 4.
