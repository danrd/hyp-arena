Прогон идёт на вашем компьютере: гипотезы и ключ никуда, кроме выбранного провайдера моделей, PubMed и открытых баз, не уходят. Результат открывается на главной странице кнопкой «Открыть свой прогон» или перетаскиванием файла; страница его никуда не отправляет.

## 1. Установить {#run-install}

Нужен Python 3.11 или новее.

```
git clone https://github.com/danrd/hyp-arena
cd hyp-arena
pip install -e .
```

## 2. Задать ключ {#run-key}

Задайте ключ хотя бы одного провайдера и разрешите платные вызовы. Подойдёт любой из ключей ниже; семейства без ключа пропускаются, с несколькими ключами проверку делают разные модели.

```
export OPENAI_API_KEY=...      # OpenAI
export ANTHROPIC_API_KEY=...   # Anthropic (Claude)
export GEMINI_API_KEY=...      # Google (Gemini)
export ALLOW_PAID=1
```

Модели и ключи задаёт `configs/v2-direct.yaml`; там же можно включить DeepSeek, xAI и Mistral (`DEEPSEEK_API_KEY`, `XAI_API_KEY`, `MISTRAL_API_KEY`) или указать `base_url` любого OpenAI-совместимого сервиса. Агрегаторы: CometAPI (`configs/v2.yaml`, ключ `COMET_API_KEY`) и бесплатные модели OpenRouter (`configs/models.yaml`, ключ `OPENROUTER_API_KEY`; качество ниже, а бесплатные эндпоинты могут сохранять запросы, поэтому неопубликованные гипотезы через них не отправляйте).

## 3. Записать гипотезы {#run-hypotheses}

Запишите гипотезы в текстовый файл, по одной на абзац (абзацы разделены пустой строкой) или нумерованным списком. Лучше всего ранжируются гипотезы о вмешательствах и механизмах старения: что, кому, в какой дозе и с каким исходом.

## 4. Запустить проверку и рейтинг {#run-go}

Несколько вызовов модели на гипотезу и несколько минут на десяток гипотез; `--max-calls` ограничивает расход.

```
python -m hyparena.card.pipeline --paste мои_гипотезы.txt \
    --config configs/v2-direct.yaml --max-calls 200 --out runs/mine.v2.json
```

## 5. Собрать файл для страницы {#run-export}

Соберите файл и откройте его на главной странице кнопкой «Открыть свой прогон».

```
python -m hyparena.site export --v2 runs/mine.v2.json \
    --title "Мои гипотезы" --out runs/site/mine.json
```

Чтобы рядом был рейтинг Elo, прогоните те же тексты турниром (`python -m hyparena.live run --import-file …`) и добавьте `--elo` и `--pool`.
