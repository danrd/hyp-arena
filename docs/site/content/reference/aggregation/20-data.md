## Типы источников {#data-types}

Для проверки важнее не формат источника, а то, что он может утверждать. Каждая запись помечается типом.

| Тип | Примеры | Может задать статус утверждения? |
|---|---|---|
| A. Первичный текст | PubMed, Europe PMC, bioRxiv | да, только с дословной цитатой роли `finding` |
| B. Курируемые записи | DrugAge, Open Genes | да, вместе с цитатой из связанной работы; само включение записи — сигнал, а не доказательство |
| C. Измерения | GTEx, GEO, IMPC, результаты на ClinicalTrials.gov | да, только через выполненную проверку с записанным результатом |
| D. Машинные выводы | PubTator, аннотации Europe PMC, баллы Open Targets | нет: подсказки для поиска |
| E. Метаданные качества | Crossref, Retraction Watch, OpenCitations | нет: флаги на других записях |
| F. Планы и деньги | даты и набор на ClinicalTrials.gov, гранты NIH RePORTER | нет: входы для оценки сроков |

Пример типа D: PubTator вывел связь «Sirolimus — Negative_Correlation — Neoplasms» из аннотации работы Harrison et al. 2009, где сказано лишь, что рапамицин «may extend lifespan by postponing death from cancer». Это предположение авторов, и статуса оно не задаёт.

| DrugAge (HAGR) | курируемые записи о влиянии веществ на продолжительность жизни; одна запись на работу и вид | CC BY 3.0; при публикациях цитировать de Magalhães et al. 2024 |

В DrugAge нет колонки с датой записи: для бэктеста дата берётся по PMID работы. Обработка ограничена аннотациями, полные тексты не читаются.

## Правило «на момент T» {#data-asof}

Бэктест оценивает рейтинг так, как если бы сегодня была дата T, а результаты стали известны позже. Чтобы будущее не просочилось в рейтинг:

- у каждой записи есть дата: для PubMed это самая ранняя публичная дата (электронная публикация, печатная, попадание в PubMed); для испытаний — дата начала; для DrugAge — дата работы по PMID;
- поиск ограничен датой: учитываются только работы, опубликованные не позже T;
- для каждого прогона бэктеста выполняется аудит дат: ни одна запись с датой позже T не должна попасть ни в один компонент (проверенные утверждения, альтернативы, отказы);
- знания языковой модели датой не ограничиваются. Устройство проверки уменьшает утечку: текст разбирается без внешних фактов, а статус требует дословной цитаты из работы, опубликованной до T. Полностью утечку это не исключает, поэтому наборов два: **чистый** (исходы появились после даты отсечки знаний используемой модели; на нём системы сравниваются) и **исторический** (T = 2010; модели могли знать исходы, поэтому на нём оценивается только эта система).

**Какая модель допустима на дату T.** Модель может проверять или судить набор с датой T, только если её отсечка знаний не позже T. Отсечка берётся из заявления разработчика (страница модели или карточка модели; для Anthropic — более широкая дата обучающих данных), а если разработчик её не указывает — дата выхода минус шесть месяцев. Модель без известной отсечки и даты выхода не допускается. Правило и значения — в `configs/model_cutoffs.yaml`; источники и цитаты по каждой модели — в `data/models/llm_cutoffs.yaml` (DeepSeek, Qwen, GLM, Mistral и Gemini 3.x отсечку не заявляют). Команда `python -m hyparena.outcomes models --as-of <T>` показывает, какие модели допустимы.

Показатель `path_to_human` в бэктесте тоже считается «на момент T» (год первого одобрения, начало испытаний; см. «Показатели»).

| человек | весь мир (если популяция из стран с низким или средним доходом) | оба · мужчины · женщины | 79,5 · 76,6 · 82,1 года | то же |

Правила подбора строки:

- нет линии: интервал по всем линиям вида; нет пола: строка «оба», если она есть, иначе интервал по полам; вида нет в таблице: значение неизвестно;
- черви и мухи: если карточка не называет условия опыта, строка подходит; если называет другие (другая температура, нет FUdR, другая линия мух, самцы), значение неизвестно, потому что медиана на них не переносится;
- максимальная продолжительность жизни из AnAge не используется: она шумная и зависит от размера выборки.

Словесный возраст превращается в интервал:

| Метка | Мышь, месяцев | Человек, лет |
|---|---|---|
| young adult, mature adult | 3–6 | 19–24 |
| adult | 3–15 | 19–44 |
| middle-aged | 10–15 | 45–64 |
| old, aged, late life, older adults, elderly | 18–24 | 65 и старше |
| very old, oldest old | старше 24 | 80 и старше |

Границы для мышей взяты из статьи The Jackson Laboratory «When are mice considered old?» (2017), для людей — из возрастных групп MeSH, которыми пользуется фильтр возраста PubMed. Пробелы в классификации (6–10 и 15–18 месяцев у мышей) заполняются объединением соседних строк. Для червей и мух словесные метки не определены: в работах возраст дан в сутках. Метка вне таблицы даёт неизвестное значение.

## Какие проверки возможны на открытых данных {#data-checks}

Гипотезу можно проверять не только литературой: многие её следствия проверяются открытыми данными (идея в духе проверки следствий по Попперу). Сначала тест записывается до просмотра данных (набор данных, переменная, сравнение, направление, статистика, порог), затем выполняется, а результат хранится как запись типа C. **В текущей версии системы эти проверки не реализованы**; ниже то, что они позволят проверить.

| Следствие гипотезы | Сильнейшая проверка на открытых данных | Сила |
|---|---|---|
| «X продлевает жизнь мышей» | данные по отдельным животным ITP: эффект по полу, площадке, когорте; поздние когорты как отложенная проверка | прямая, если X был в ITP |
| «X продлевает жизнь червей (устойчиво)» | данные по отдельным червям CITP: линии, виды, лаборатории | прямая |
| «Результат на червях или мухах перенесётся на мышей» | базовые частоты переноса по DrugAge и ITP | косвенная (априорная) |
| «X замедляет старение, а не одну болезнь» | молекулярные оценки по данным печени ITP (GSE292884) против исходов ITP; направление возрастных изменений по Tabula Muris Senis; эпигенетические часы | косвенная |
| «X действует как известные геропротекторы» | связность профилей экспрессии (LINCS L1000) с сигнатурами продления жизни | косвенная |
| «Мишень T важна для продолжительности жизни человека» | менделевская рандомизация по мишеням: GWAS продолжительности жизни родителей, инструменты pQTL и eQTL | квазипричинная |
| «X снижает смертность или улучшает функцию у людей» | сравнение с активным препаратом по NHANES со связью со смертностью; результаты ClinicalTrials.gov; CALERIE для ограничения калорий | наблюдательная или РКИ по суррогатам |
| «X безопасен при длительном приёме» | диспропорциональность сообщений FAERS, ограничения по эволюционной консервативности (gnomAD), нежелательные явления в испытаниях | только опровержение |

Основные группы источников:

| Группа | Источники | Ограничения |
|---|---|---|
| Животные, исходы вмешательств | ITP через Mouse Phenome Database, CITP, DrugAge, Open Genes, RAID, SynergyAge | ITP и CITP публикуют отрицательные результаты; DrugAge и Open Genes курируются, RAID содержит только значимые эффекты |
| Молекулярные данные | GEO (GSE292884), LINCS L1000, Tabula Muris Senis, наборы генов клеточного старения (SenMayo, CellAge), Biolearn (эпигенетические часы), GTEx | разные ткани, линии клеток, схемы; сигнатуры и часы обучены на данных, которые могут пересекаться с проверочными |
| Люди | NHANES со связанной смертностью, ClinicalTrials.gov, CALERIE, openFDA FAERS | наблюдательные данные подвержены смещению по показанию; FAERS не знает знаменателя |
| Генетика человека | GWAS продолжительности жизни родителей (Timmers et al. 2019), составной показатель старения mvAge (Rosoff et al. 2023), UKB-PPP pQTL, OpenGWAS, eQTL | слабые инструменты для многих мишеней; перекрытие выборок экспозиции и исхода |

Правило отложенной выборки: до того как называть проверку независимой, выясняется, на каких данных обучена сигнатура или часы, и эти данные исключаются из проверки. Условия доступа и лицензии меняются; перед использованием источника их нужно перепроверять.

## Историческая проверка ITP {#data-itp}

Проверка отвечает на вопрос: что показал бы рейтинг, если бы сегодня был конец 2010 года, и что программа ITP опубликовала позже. Слово «предсказание» здесь не используется: это рейтинг на дату T и то, что опубликовано после неё.

- **Пул.** T = 2010-12-31. Тесты Interventions Testing Program из DrugAge (строки с пометкой ITP): один тест на соединение, дозу и возраст начала приёма. В пул входит тест, первая публикация которого вышла после T. Всего 70 тестов (49 соединений; одно соединение может быть несколькими тестами, «режимами»). Текст гипотезы называет вмешательство и заявленный эффект, но не результат.
- **Что видит система.** Работы PubMed и записи DrugAge не позже T; для каждого прогона выполнен аудит дат (ни одна запись позже T не попала в расчёт). Знания языковых моделей датой не ограничены, поэтому модели могли знать более поздние работы: это историческая проверка, а не чистая.
- **Метки.** Лежат в отдельном файле, который система не читает. «Продлило» — значимое увеличение средней продолжительности жизни хотя бы у одного пола; «вред» — только значимые снижения; иначе «нет эффекта». Вместе с меткой хранятся результат по полу, наибольший эффект (% изменения средней продолжительности жизни), дата и PMID первой публикации ITP. Распределение: 27 продлило, 40 нет эффекта, 3 вред.
- **Разбиение.** Пул поделён на две половины (dev и test) детерминированно: по хешу названия соединения, по меткам поровну; 11 соединений встречаются в обеих половинах. Правило основной метрики выбрано на dev до прогона test, а test прогнан один раз. Каждая половина ранжировалась отдельным прогоном (проверку делала одна модель, DeepSeek V4.1 Flash; карточки собирал Gemini; 110 и 126 вызовов, без ошибок).
- **Основная метрика.** AUC по соединениям в рейтинге без `late_start`, известные результаты отдельно. Показатель `late_start` исключён, потому что ITP выбирала поздний старт для соединений, уже сработавших раньше, и показатель мог читать это более позднее решение. Правило метрики выбрано на dev до прогона test, а test прогнан один раз. По рейтингам половин, посчитанным каждая отдельно, в первом прогоне: dev 0.53 [0.29, 0.77] (6 положительных, 21 отрицательное), test 0.73 [0.53, 0.89] (10 и 22). С поздним стартом полный рейтинг давал 0.83 на dev и 0.77 на test; эти числа справочные.
- **Метрика без зависимости от seed.** Позже выяснилось, что AUC зависит от случайного зерна (seed) расчёта: у большой группы режимов ожидания различаются меньше погрешности моделирования (в одном из рейтингов 42 режима «на равных»), и их порядок внутри группы определяется шумом. На восьми разных seed AUC по режимам для общего рейтинга колебался от 0.65 до 0.76; опубликованные для seed 0 числа попадают в разные части этого разброса. Поэтому на странице и ниже используется AUC с ничьёй: два режима, ожидания которых различаются меньше 1,96·√((σ<sub>A</sub>² + σ<sub>B</sub>²)/K), считаются равными и дают по половине очка. Это те же группы «на равных», что и в таблице; результат от seed не зависит. Функции `backtest.primary` (seed 0) и `backtest.primary_tied` (с ничьёй) считают одну и ту же метрику, различается только обращение с такими парами. Значение 0.53 для dev при расчёте без зависимости от seed равно 0.68: отличие половин (0.53 и 0.73) в значительной мере объясняется шумом порядка.
- **Изменения после первого прогона** (один список; по этой выборке правила больше не меняются; карточки и проверки не пересобирались, правила применены к сохранённым записям без вызовов моделей, `backtest reapply`, режим `--legacy` воспроизводит прежний прогон):
  1. **Охват по полу** (раздел [«Охват по полу»](#statuses-sex)). Гипотеза «хотя бы у одного пола» оспаривалась нулевым результатом у другого пола. Статус основного утверждения изменился у четырёх режимов, все четыре из «оспорено» стали «подтверждено» и, как следствие, «известным результатом» (вне рейтинга): аспирин 200 ppm, нордигидрогваяретовая кислота 800 и 2500 ppm (половина dev), нордигидрогваяретовая кислота 5000 ppm (половина test).
  2. **Контекст «модель болезни»** (раздел [«Контекст: модели болезней»](#statuses-disease)). Записи из моделей болезней больше не задают статус утверждения про обычных животных. В ITP-пуле аналог получили 11 режимов (4 в dev: фиш-ойл 15000 ppm, рапамицин 4.7 и 42 ppm, ресвератрол; 7 в test: фиш-ойл 50000 ppm, метформин, миноциклин 300 ppm, микофеноловая кислота, урсодезоксихолевая кислота, рапамицин 42 ppm с двумя возрастами начала); статус и исход не изменились ни у одного режима, потому что статусы держались на записях об обычных мышах. У двух режимов половины test (миноциклин 300 ppm, микофеноловая кислота) новизна `analog` стала `new_link`, поскольку их «аналог» состоял из записей моделей болезней. Известным результатом никто не стал и не перестал.
  3. **Метрика с ничьёй** (предыдущий пункт про seed): меняет способ счёта, а не рейтинг.
  4. **Разведочный пересчёт 2026-10-23** (изменения (а) и (б), см. раздел «Геометрия весов и набор показателей» и «Новизна»): `multi_site_positive` стал условием `robustness`, новизна неизвестна без опоры в литературе. Исходы и статусы не изменились ни у одного режима; `robustness` не изменился ни у одного; новизна стала неизвестной у 54 из 61 режима в рейтинге. **Первый прогон остаётся эталоном** (числа выше и страница); пересчёт опубликован отдельно как разведочный, потому что тестовая половина уже использована: AUC по режимам 0,58 [0,48; 0,68] против 0,65 [0,56; 0,74] у эталона, среди 15 последних режимов находок 4 вместо 1. Интервалы перекрываются, правила под метки не подгонялись. Колонки `*_ab` в `docs/itp_2010_changes_after_first_run.csv`, снимок `tests/fixtures/itp2010_exploratory_snapshot.csv`.
  - **`informativeness` на этой выборке не считается.** Первый прогон был до показателя; считать его на ITP значило бы пересобирать карточки и вызывать модели по замороженной выборке, то есть менять эталон. Он остаётся неизвестным у всех режимов (в отчёте по пулу это видно как «неизвестен у всех»). Показатель считается только в новых прогонах на выборках, где правила ещё не зафиксированы.
  5. **Определение `path_to_human`** (2026-10-25): убран шаг «мышиное исследование, если нет подтверждённого эффекта у млекопитающих» (он считал `effect_level` второй раз), остались два уровня по безопасности; показатель подписан «насколько дёшево проверить сейчас, а не насколько верно». После трёх изменений вместе (колонки `*_abp`, снимок `tests/fixtures/itp2010_exploratory2_snapshot.csv`): значение изменилось у 50 из 70 режимов, статусы и исходы не изменились, первые два места те же (рапамицин, метформин); динитрофенол выбыл из первой четвёрки, в неё вошёл куркумин (imp026), AUC по режимам 0,605 [0,49; 0,72] (эталон 0,65 [0,56; 0,74]), среди 15 последних находка одна; профиль упорядочивает 64–65% пар (у эталона 46–48%), ведущий показатель `path_to_human` создаёт 36–37% упорядоченных пар (у эталона 47–50%). Разведочные числа, правила под метки не подгонялись.
