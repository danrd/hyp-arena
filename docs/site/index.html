hyp-arena

Ранжирование гипотез о старении по проверенным фактам

Гипотеза превращается в карточку утверждений, утверждения проверяются по PubMed и DrugAge с дословными цитатами, а рейтинг строится при явно заданных приоритетах.

Свои гипотезы со своим ключом

Прогон идёт на вашем компьютере; результат открывается кнопкой «Открыть свой прогон».

git clone https://github.com/danrd/hyp-arena && cd hyp-arena && pip install -e .
export OPENAI_API_KEY=...   # или ANTHROPIC_API_KEY, GEMINI_API_KEY
export ALLOW_PAID=1
python -m hyparena.card.pipeline --paste мои_гипотезы.txt \
    --config configs/v2-direct.yaml --max-calls 200 --out runs/mine.v2.json

Нажмите на команду, чтобы скопировать. Подробнее: ключи, провайдеры, формат гипотез, сборка файла для страницы.

Проверка метода

Как мы проверяем, что рейтинг что-то значит

Выборки маленькие, интервалы широкие: цифры показывают направление, а не точность.

Эталонные примеры

4 из 4

основное утверждение совпало с эталоном

Это четыре примера (1, 2, 3 и 5), которые проходят через верификатор на реальной литературе. Пример 4 проверяет допуск и в счёт не входит.

Расхождения есть у побочных утверждений: в примере 1 два, в примере 2 одно (статьи новее эталона, обобщённые формулировки).

Доказывает: верификатор воспроизводит вывод по основному утверждению там, где нужны трудные правила (контраст, подгруппа, несовпадение исхода, контекст). Не доказывает: качество на произвольных гипотезах: примеров четыре и подобраны они под эти правила.

Тест с негативными примерами

0.81

AUC, 95% ДИ [0.63, 0.96], 6 групп

В каждой группе одно подтверждённое открытие среди девяти правдоподобных ложных утверждений. Случайный порядок даёт 0.50; открытие на первом месте в половине групп.

Доказывает: метод заметно лучше случайного отличает подтверждённое от правдоподобного ложного. Не доказывает: умение выбирать среди открытых гипотез: групп шесть, интервал широкий, а модели могли помнить эти открытия.

Исторический бэктест ITP

0.73

AUC по соединениям, 95% ДИ [0.53, 0.89], тестовая половина

Рейтинг на конец 2010 года, исходы — результаты Interventions Testing Program после 2010. На dev-половине та же метрика 0.53.

Возраст начала приёма из бэктеста исключён: поздний старт ITP выбирала для соединений, уже сработавших раньше, и показатель читал это будущее решение.

Доказывает: на гипотезах с неизвестным в 2010 году исходом рейтинг даёт сигнал выше случайного: 0.73 на тестовой половине. Не доказывает: устойчивую предсказательную силу: на dev-половине 0.53, выборка маленькая (10 положительных соединений на тесте), интервал широкий.

Границы применимости и открытые вопросы: в документации.

hyp-arena · исследовательский прототип; рейтинги — результат исследования, а не медицинская рекомендация. Проверка опирается на PubMed (NCBI) и DrugAge (HAGR); цитаты приводятся дословно со ссылкой на источник.
