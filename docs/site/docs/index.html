Запуск

Как проверить свои гипотезы со своим ключом и посмотреть результат на главной странице.

Что получится #

Вы загружаете свои гипотезы и получаете рейтинг и карточки с цитатами из статей. Результат открывается на главной странице сайта, там же можно скачать таблицу. Всё считается на вашем компьютере.

Что понадобится #

  • Python 3.11 или новее.
  • Ключ хотя бы одного провайдера языковых моделей: OpenAI, Anthropic или Google. Это платный доступ к модели, обычно его выдают в личном кабинете провайдера.
  • Немного времени и денег. На одну гипотезу уходит несколько вызовов модели, на десяток гипотез — несколько минут (в примере на сайте 37 вызовов на десять гипотез). Сколько это стоит, зависит от провайдера и модели. Расход можно ограничить параметром --max-calls: когда лимит вызовов кончится, запуск остановится.

Шаг 1. Установить #

Откройте терминал и выполните:

git clone https://github.com/danrd/hyp-arena
cd hyp-arena
pip install -e .

Что вы увидите, если всё хорошо. Последняя строка вывода начинается со слов «Successfully installed».

Шаг 2. Задать ключ #

Укажите ключ хотя бы одного провайдера и разрешите платные вызовы. Подойдёт любой из ключей; провайдеры без ключа пропускаются, а если ключей несколько, проверку делают разные модели.

export OPENAI_API_KEY=...      # OpenAI
export ANTHROPIC_API_KEY=...   # Anthropic (Claude)
export GEMINI_API_KEY=...      # Google (Gemini)
export ALLOW_PAID=1

Команды написаны для bash и zsh. В PowerShell на Windows то же самое выглядит так: $env:OPENAI_API_KEY="...". Переменные действуют только в том окне терминала, где вы их задали.

Модели и ключи описаны в файле configs/v2-direct.yaml. В нём можно включить DeepSeek, xAI и Mistral (DEEPSEEK_API_KEY, XAI_API_KEY, MISTRAL_API_KEY) или указать base_url любого сервиса, совместимого с OpenAI. Агрегаторы: CometAPI (configs/v2.yaml, ключ COMET_API_KEY) и бесплатные модели OpenRouter (configs/models.yaml, ключ OPENROUTER_API_KEY). Качество у бесплатных моделей ниже; читайте предупреждение в разделе «Конфиденциальность».

Что вы увидите, если всё хорошо. Ничего: команды export молчат. Проверить можно так: echo ${OPENAI_API_KEY:+ключ задан} выведет «ключ задан».

Шаг 3. Записать гипотезы #

Создайте текстовый файл мои_гипотезы.txt. Пишите гипотезы по одной на абзац (между абзацами пустая строка) или нумерованным списком:

1. Метформин, который мыши получают с середины жизни, продлевает их жизнь.

2. Рапамицин улучшает здоровую продолжительность жизни у пожилых людей.

Лучше всего работают гипотезы о вмешательствах и механизмах старения: что, кому, в какой дозе и с каким исходом.

Что вы увидите, если всё хорошо. Файл открывается в обычном текстовом редакторе, и в нём читаются ваши гипотезы. Отдельной проверки на этом шаге нет, формат проверится при запуске.

Шаг 4. Запустить проверку и рейтинг #

python -m hyparena.card.pipeline --paste мои_гипотезы.txt \
    --config configs/v2-direct.yaml --max-calls 200 --out runs/mine.v2.json

Что вы увидите, если всё хорошо. Программа по ходу работы пишет, на каком этапе она находится. В конце выводит по строке на каждую гипотезу с её исходом («ranked» значит «в рейтинге»), рейтинг по каждому профилю и итог: число вызовов, время и имя файла runs/mine.v2.json.

Шаг 5. Собрать файл для страницы #

python -m hyparena.site export --v2 runs/mine.v2.json \
    --title "Мои гипотезы" --out runs/site/mine.json

Затем откройте главную страницу сайта, нажмите «Открыть свой прогон» и выберите файл runs/site/mine.json. Файл можно и перетащить на страницу.

Чтобы рядом был рейтинг Elo (турнир, в котором модели спорят о гипотезах), прогоните те же тексты турниром командой python -m hyparena.live run --import-file … и добавьте в команду выше параметры --elo и --pool.

Что вы увидите, если всё хорошо. Команда печатает путь к созданному файлу. На главной странице вместо примера появляются ваши гипотезы: метка «Пример» исчезает, в полосе стоит название вашего прогона, а во вкладке «Сравнение» — ваш рейтинг.

Конфиденциальность #

Ваши гипотезы и ключ не уходят никуда, кроме выбранного провайдера моделей, PubMed и открытых баз. Страница результат никуда не отправляет: файл читается в вашем браузере.

Бесплатные эндпоинты OpenRouter могут сохранять запросы, поэтому неопубликованные гипотезы через них не отправляйте.

Если что-то не работает #

Запуск пишет «No API key is set for any model of this config». Ключ не задан в этом окне терминала. Выполните шаг 2 в том же окне, где запускаете программу. Если ключ задан, но провайдер отвечает ошибкой доступа, проверьте сам ключ и то, что у него есть доступ к модели из configs/v2-direct.yaml.

Запуск пишет «is a paid model; set ALLOW_PAID=1 to use it». Платные вызовы по умолчанию выключены. Выполните export ALLOW_PAID=1.

Запуск остановился с сообщением «call cap of … reached». Закончился лимит вызовов из параметра --max-calls. Увеличьте его (по умолчанию 400) и запустите снова; чем больше гипотез, тем больше вызовов нужно.

Программа прочитала весь файл как одну гипотезу. Гипотезы разделяются пустой строкой или нумерацией «1.», «2)»; нумерация засчитывается, если пунктов не меньше двух. Если всё написано подряд, строка за строкой, разделите их пустыми строками.

Страница пишет «Это не файл страницы». Вы выбрали не тот файл. Нужен результат шага 5 (runs/site/mine.json), а не файл runs/mine.v2.json из шага 4.

Карточка гипотезы

Как текст гипотезы превращается в структуру, которую можно проверять по частям.

Слои #

Карточка строится в четыре шага. Слои не смешиваются: рейтинг читает только проверенный слой.

Слой Кто пишет Что внутри
Текст автор или модель гипотеза как есть
Допуск программа accepted, needs_refinement или not_a_hypothesis
Заявленный слой нормализатор (языковая модель) PICO и утверждения только из текста, без статусов и цитат
Проверенный слой верификатор (языковая модель) и правила для каждого утверждения цитаты за и против, отказы и статус; профиль доказательности

Три принципа:

  • неустановленное остаётся unknown, значений по умолчанию нет;
  • любой статус, кроме «не проверено» и «не распознано», держится хотя бы на одной цитате, дословно найденной в источнике;
  • проверки необходимых условий могут только отказать, подтвердить утверждение они не могут.

Допуск #

Гипотеза — это утверждение, для которого можно задать решающий эксперимент: систему, исход и класс длительности. Всё остальное — «направление» (например, «мишень X стоит изучать»). Направление хранится, но не ранжируется.

Тип Обязательно Желательно (не блокирует)
interventional вмешательство, вид или популяция, исход доза и режим, пол, возраст начала, сравнение
mechanistic вещество или вмешательство, объясняемый эффект, хотя бы одно утверждение-механизм или исход с контрастом как у вмешательства
biomarker маркер, предсказываемый исход, популяция сравнение (обычно хронологический возраст)
observational воздействие или вариант, исход, популяция дизайн, когорта

Три исхода допуска:

  • accepted: все обязательные поля есть, гипотеза идёт в проверку и ранжирование;
  • needs_refinement: поля не хватает, но высказывание можно уточнить. Гипотеза попадает в список «ждут уточнения» с перечнем недостающих полей и не пропадает молча;
  • not_a_hypothesis: исход нельзя измерить или утверждение нельзя опровергнуть. Текст хранится как направление с причиной.

Примеры: «Senolytics slow aging» получает needs_refinement (класс препаратов вместо вещества, нет вида, нет измеримого исхода). «Senescent cells are bad for health» получает not_a_hypothesis (нет вмешательства и измеримого исхода).

Если основное утверждение уже подтверждено в том же контексте (то же вмешательство, вид, пол, возраст, доза), гипотеза помечается как известный результат: новизны у неё нет, и в рейтинг она не входит, а показывается отдельно.

PICO #

PICO описывает исследование целиком. Каждое поле либо взято из текста, либо unknown.

Поле Что значит Пример
population.taxon, label организм или популяция NCBITaxon:9606, human
population.strain линия животных UM-HET3
population.sex пол female
population.age_at_start возраст популяции в начале вмешательства: метка или число older adults, 600 days
intervention[] вмешательство; для комбинации несколько. Тип: compound, gene, diet, procedure {type: compound, label: rapamycin, id: CHEBI:9168}
intervention.regimen режим так, как он назван в тексте weekly, low-dose, intermittent
intervention.route как вводится: diet, water, oral, injection, topical, other, unknown diet (в корме)
comparator с чем сравнивают: placebo, untreated, standard_care, wild_type, monotherapy, active_drug, chronological_age, other placebo
outcome.endpoint что измеряется: lifespan, healthspan, biomarker, disease, mechanism healthspan
outcome.metric чем измеряется physical function
time срок unknown

Недостающее поле не достраивается из общих знаний. Если в тексте нет сравнения, в карточке comparator: unknown, а не «обычная диета».

Утверждения #

Утверждение — одна связь «субъект — отношение — объект» в одном контексте, которую можно проверить источником одного типа.

Поле Что значит Пример
id номер внутри карточки c1
subject что действует rapamycin
relation отношение из закрытого словаря (ниже) inhibits
object на что направлено mTORC1
qualifiers уточнения контекста: species, strain, sex, tissue, dose, age_at_start, comparator, direction, measure, contrast {species: human}
inherited_from_pico какие уточнения взяты из PICO, а не из слов утверждения (только species и strain) [species]
role роль в гипотезе (ниже) outcome
source_span дословный фрагмент текста, из которого утверждение взято «by inhibiting mTORC1»

Правила: в карточке ровно одно утверждение с ролью outcome; утверждений не больше восьми; у каждого есть source_span. Утверждение, которого нет в тексте, в заявленный слой попасть не может (аналоги позже добавляет верификатор в своём слое).

Пример. Текст: «Weekly low-dose intermittent rapamycin, by inhibiting mTORC1, slows multiple aspects of aging and can improve healthspan in healthy older adults, as it does in mice where it extends lifespan even when started late in life.» Нормализатор разбирает его на четыре утверждения:

id Роль Утверждение Фрагмент текста
c1 посылка rapamycin inhibits mTORC1 «by inhibiting mTORC1»
c2 механизм rapamycin slows_aging_in human «slows multiple aspects of aging»
c3 аналог rapamycin extends_lifespan_in mouse «in mice where it extends lifespan even when started late in life»
c4 исход rapamycin improves_healthspan_in human «can improve healthspan in healthy older adults»

Роли #

Роль Что значит Пример (выше)
outcome корневое утверждение гипотезы; ровно одно c4
premise то, на что гипотеза опирается как на данность, или то, что она объясняет c1
mechanism звено объяснения c2
analog то же вмешательство в другом организме, поддерживающее исход c3
translation явный перенос находки с одного вида на другой «то, что работает у мышей, должно работать у людей»

Связи между утверждениями: requires (c1 верно, только если верно c2), supports_if_true, analog_of, contradicts.

Словарь отношений #

Словарь закрытый: нормализатор выбирает отношение из списка. Если ничего не подходит, ставится other с короткой пометкой.

Отношение Субъект → объект Что значит
extends_lifespan_in вмешательство → организм увеличивает среднюю, медианную или максимальную продолжительность жизни
shortens_lifespan_in вмешательство → организм уменьшает продолжительность жизни
no_lifespan_effect_in вмешательство → организм проверено, значимого эффекта нет
slows_aging_in вмешательство → организм замедляет возрастные изменения, не связанные с одной болезнью; что именно измерено, записывается в qualifiers.measure
improves_healthspan_in вмешательство → организм улучшает показатель здоровой продолжительности жизни
changes_biomarker вмешательство → маркер меняет маркер; направление в уточнениях
predicts маркер → исход значение маркера предсказывает исход (гипотезы о маркерах)
inhibits, activates вещество → молекулярная мишень прямое воздействие на мишень
increases_expression, decreases_expression вещество → ген или белок изменение экспрессии
promotes, suppresses вещество или процесс → процесс или фенотип причинное усиление или подавление
part_of сущность → путь или процесс принадлежность
associated_with любое → любое связь без утверждения о причине
affects_hallmark сущность или процесс → примета старения одна из 12 примет старения; направление в уточнениях
translates_to находка у вида A → вид B явный перенос между видами (связь с низким доверием)
other любое → любое помечается и не участвует в проверках

Если other оказался у исходного утверждения, нормализатор перечитывает текст ещё раз, получив подсказку с ближайшими отношениями словаря. Если и после этого other, гипотеза получает флаг unmapped_relation, не ранжируется и попадает в список «не разобраны»: её содержание может быть в порядке, а пробел — в словаре.

Как делить текст на утверждения #

  • Одно отношение на утверждение: «рапамицин ингибирует mTORC1 и снижает старение клеток» — два утверждения.
  • Один контекст на утверждение: «продлевает жизнь мышей и мух» — два утверждения.
  • Цепочки механизма — отдельные утверждения со связью requires.
  • Пол, доза и возраст остаются в одном утверждении, если текст не приписывает им разные эффекты.
  • Комбинация: все компоненты перечисляются в intervention; утверждение о синергии («лучше каждого по отдельности») — отдельное, с comparator: monotherapy.

Контраст «в основном X, а не Y». Смысл такой гипотезы — в сравнении двух объяснений. Исходное утверждение — X (заявленное объяснение), с уточнением contrast, которое указывает на Y. Y записывается как отвергаемая альтернатива со своим дословным фрагментом, а объясняемый эффект — как посылка.

Пример: «Rapamycin extends mouse lifespan mainly by postponing death from cancer, not by slowing aging itself.» Посылка: rapamycin extends_lifespan_in mouse. Исход (X): rapamycin suppresses cancer mortality. Отвергаемая альтернатива (Y): rapamycin slows_aging_in mouse, «not by slowing aging itself». Как статус исхода зависит от Y, описано в разделе «Статусы».

Запись-доказательство #

Каждая цитата, на которой держится статус, хранится как запись.

Поле Что значит Пример
source, record_id где найдено и под каким номером PubMed, PMID:19587680
epistemic_type что источник способен утверждать: A_text (первичный текст), B_curated (курируемая запись базы), C_measurement (выполненное измерение). Машинные выводы, метаданные качества и планы статус не задают A_text
study_type вид исследования rct
lab_or_cohort группа, когорта или испытание; независимость повторов считается по этому полю PMID:40188830
derived_from если запись — обзор или повторный анализ тех же данных; она устойчивости не добавляет review
species, strain, sex, dose, age_at_start контекст находки так, как он дан в источнике mouse, UM-HET3, female, 14 ppm in food, 600 days
human_rungs только у людей: human_markers (лабораторные и инструментальные измерения) и (или) human_clinical (самочувствие, функция, болезни, смертность) [human_markers] для массы мышечной ткани
quote дословный фрагмент источника «Lean tissue mass (ηp2 = 0.202, p = 0.013) … improved significantly for women using 10 mg rapamycin.»
quote_role finding (результат этой работы), background (известное, цитируется), speculation («возможно», «предполагаем»). Статус меняет только finding finding
qualifiers_match совпадает ли контекст находки с утверждением: yes, no или n/a по виду, линии, полу, возрасту, дозе, сравнению; отдельно intervention_match: exact, dose_differs, regimen_differs, related_compound, class {species: yes, sex: n/a}
marker_validation для маркеров у человека: validated_surrogate или exploratory exploratory
flags предупреждения: retracted, preprint, conflict_of_interest, small_n, open_label, subgroup_only, short_lived_controls [subgroup_only]
linked_pmid, fields только у курируемых записей: работа, из которой взята строка, и поля самой строки 19587680; avg_lifespan_change_percent: 13

Флаги видны читателю и судьям и статус сами не меняют. Исключения: запись с флагом retracted не учитывается, а subgroup_only участвует в правиле подгруппы.

Статусы и правила проверки

Как найденные цитаты превращаются в статус утверждения.

Пять статусов #

Статус считает программа по найденным записям. Языковая модель только извлекает цитаты и их признаки, а решает правило.

Статус Когда Пример
подтверждено (supported) есть хотя бы одна находка «за» (finding) в совпадающем контексте и нет подходящих находок «против» «rapamycin extends lifespan in mouse»: Harrison et al. 2009 (PMID 19587680) и записи DrugAge
оспорено (contested) есть находки и «за», и «против» в совпадающем контексте; либо единственная поддержка — подгруппа или вторичный исход при нулевом первичном «rapamycin improves healthspan in older adults»: в испытании PEARL положительны подгруппа женщин и вторичные исходы, первичный исход нулевой
опровергнуто (refuted) есть находки «против» и нет «за» «resveratrol extends lifespan in mice»: две работы не нашли эффекта (PMID 18599363, PMID 20974732)
не проверено (unverified) подходящих находок нет; фон и предположения не считаются «rapamycin inhibits mTORC1»: найдена только фраза-фон «an inhibitor of the mTOR pathway»
не распознано (unresolved) сущности не удалось сопоставить с идентификаторами или отношение other, проверить утверждение нельзя вещество, которого нет в справочниках

«Оспорено» означает, что находки есть и по ним спорят. Отсутствие находок — это «не проверено», и такое утверждение в споры о противоречивых данных не попадает.

Что считается находкой #

Запись влияет на статус, только если выполнены все условия:

  1. quote_role: finding: это результат работы, а не фон и не предположение;
  2. тип источника A_text, B_curated или C_measurement;
  3. ни одно уточнение контекста не отмечено как несовпадение (no);
  4. запись о том же веществе: родственные вещества и классы считаются только аналогами;
  5. запись не отозвана и не из пробирки или экспланта, если утверждение об организме;
  6. исход записи совпадает с исходом утверждения.

Цитата засчитывается только дословная: каждая цитата проверяется программой как точная подстрока текста аннотации, остальные отбрасываются.

Исход должен совпадать #

Находка подтверждает или опровергает утверждение, только если измеряет то же самое. Улучшение здоровья не доказывает продление жизни, а маркер не доказывает ни то ни другое. Такие записи уходят в отказы с типом endpoint_mismatch и остаются видны.

Пример: «Resveratrol started in middle age extends the lifespan of mice.» Аннотация PMID 18599363 сообщает «resveratrol-fed elderly mice show a marked reduction in signs of aging» (здоровье) и «mice fed a standard diet did not live longer» (жизнь). Первая фраза уходит в отказы, вторая опровергает утверждение.

Исключение: для утверждения о здоровой продолжительности жизни у человека маркерные находки засчитываются на ступени «человек: маркеры».

Совпадение контекста #

  • Если уточнение в карточке unknown, то в qualifiers_match стоит n/a, а не no: неизвестное сравнение, пол или возраст несовпадением не становится. n/a считается совпадением.
  • Если источник уточнение не сообщает, оно просто не записывается и ничего не блокирует.
  • Доза, заданная словами («низкая доза»), не считается несовпадением с числовой дозой в источнике.
  • Линия. Если линия в карточке не указана, подходит любая линия вида. Если указана и находка получена в другой линии, запись напрямую не засчитывается: верификатор добавляет утверждение-аналог (то же вмешательство, тот же вид, другая линия). Аналог влияет на уровень эффекта, но не делает гипотезу известным результатом.
  • Для курируемых записей intervention_match ставится по полям: способ введения в карточке и в записи различаются (ppm в корме и режим «раз в неделю») — regimen_differs.
  • Сравнение важно: данные против нелеченого контроля не подтверждают утверждение о превосходстве над монотерапией. Короткоживущий контроль — известный источник ложных эффектов, он помечается флагом short_lived_controls.

Наследование из PICO #

Если утверждение о самом вмешательстве не называет вид или линию, они берутся из PICO и перечисляются в inherited_from_pico. Условия жёсткие и поэтому результат однозначный:

  • наследуются только species и strain;
  • только в утверждения, субъект которых — вмешательство (и в отвергаемые альтернативы);
  • только если фрагмент текста сам их не называет (организм в объекте, например «in mice», считается названным видом);
  • никогда в молекулярные отношения (inhibits, activates, increases_expression, decreases_expression, part_of) и в общие утверждения о механизме;
  • значение записывается чистым: species: human, а не «human (из PICO)».

Унаследованное значение не было сказано в тексте, поэтому его несовпадение — мягкий отказ inherited_mismatch: запись видна, но статус не меняет.

Пример: «rapamycin … slows multiple aspects of aging … in healthy older adults». Вид «человек» унаследован из PICO. Работа Wilkinson et al. 2012 (PMID 22587563) показывает замедление старения у мышей. Это отказ inherited_mismatch, утверждение остаётся «не проверено».

Контраст «X, а не Y» #

Верификатор проверяет отвергаемую альтернативу Y как обычное утверждение, в обоих направлениях: ищет и подтверждения, и опровержения, и не останавливается на первой подходящей находке. «Тот же контекст» означает тот же вид и ту же линию, если обе указаны.

Статус исхода X по порядку правил:

X (заявленное) Y (отвергаемое) Исход
опровергнуто любой опровергнуто
любой подтверждено опровергнуто (даже если X подтверждено)
любой другой оспорено оспорено
любой другой опровергнуто статус X
подтверждено не проверено или не распознано не проверено, флаг contrast_unchecked
любой другой не проверено или не распознано статус X

Поддержка «в подарок» не даётся: пока Y не проверено, подтверждённое X остаётся «не проверено» с флагом, а записи в пользу X остаются видны. «Оспорено» — это находки и за, и против, а при непроверенном Y противоречащих находок нет.

Пример: «Rapamycin extends mouse lifespan mainly by postponing death from cancer, not by slowing aging itself.» Y — «rapamycin slows aging in mice». Wilkinson et al. 2012 («rapamycin retards multiple aspects of aging in mice») за Y, Neff et al. 2013 (PMID 23863708, «our data largely dissociate rapamycin's longevity effects from effects on aging itself») против. Y оспорено, значит исход оспорен, и гипотеза остаётся в рейтинге.

Только подгруппа #

Положительный результат в подгруппе или по вторичному исходу (запись с флагом subgroup_only) сам по себе никогда не даёт «подтверждено».

  1. Если результат по всей выборке или по первичному исходу той же работы не найден, верификатор делает один прицельный запрос: аннотация работы и, если испытание зарегистрировано, запись в ClinicalTrials.gov.
  2. Первичный исход нулевой или отрицательный: «оспорено». Положительный: «подтверждено».
  3. Ничего не найдено: «не проверено» и флаг subgroup_unchecked. Запись по подгруппе остаётся видна судьям и эксперту.

Нулевой исход, который не удалось найти, — не находка, поэтому «не проверено», а не «оспорено» (так же, как с contrast_unchecked).

Пример: в испытании PEARL (PMID 40188830) масса мышечной ткани и боль улучшились «for women using 10 mg rapamycin» (подгруппа), а первичный исход «Visceral adiposity did not change significantly». Это «оспорено» на обеих ступенях, «маркеры» и «клиника».

Отказы #

Запись, которая выглядит подходящей, но не может влиять на статус, уходит в отказы с причиной и остаётся видна читателю и судьям.

Тип Когда
endpoint_mismatch находка измеряет другой исход, чем утверждение
inherited_mismatch несовпадение по значению, унаследованному из PICO (например, находка у мыши при унаследованном виде «человек»)
type_mismatch, direction_mismatch, species_mismatch предусмотрены схемой (тип источника, направление эффекта, вид); текущая версия верификатора их не выставляет; несовпадение вида просто делает запись неподходящей (species: no)

Фильтр и известный результат #

Если исходное утверждение, утверждение-механизм или посылка опровергнуты, гипотеза отсеивается, причина — опровергающая запись. «Оспорено» не отсеивает: гипотеза остаётся и показывает спор.

Если исходное утверждение уже подтверждено в том же контексте, это известный результат: в рейтинг он не входит.

Показатели

Какие числа и уровни считаются из проверенной карточки и что означает каждый.

Профиль доказательности #

Из статусов утверждений считается профиль доказательности. Это факты, а не оценки: одна ось не обменивается на другую, а то, насколько важна каждая, решает профиль приоритетов при агрегации.

Фильтр. Если опровергнуто исходное утверждение, механизм или посылка, гипотеза отсеивается с указанием опровергающей записи. «Оспорено» не отсеивает.

Ось Значения Откуда
effect_level none · cells · invertebrates · mammals · human_markers · human_clinical высшая ступень, на которой подтверждено исходное утверждение или утверждение-аналог с тем же вмешательством; родственные вещества и классы считаются только аналогами. Оспоренная более высокая ступень указывается рядом
robustness single · replicated на этой ступени одна работа или не менее двух независимых (разные lab_or_cohort; обзоры и повторные анализы не считаются). Эффект на двух и более площадках многоцентровой программы тоже считается повтором
mechanism unverified · partial · supported подтверждены ли утверждения-механизмы и посылки: ни одно · часть · все

Отдельно отмечаются:

  • многоцентровая программа (multi_site_program): вмешательство проверено на этой ступени в стандартизованной программе с публикацией отрицательных результатов (ITP для мышей, CITP для червей); исход программы положительный или отрицательный. Это не уровень устойчивости: многоцентровость проверяет воспроизводимость в одном протоколе, независимый повтор проверяет обобщаемость, и между ними порядок не вводится;
  • конфликты (conflicts): на каком уровне какие записи за и какие против; кто побеждает, правило не решает;
  • ступени у человека определяются по исходу записи. human_markers: лабораторные и инструментальные измерения (маркеры крови, эпигенетические часы, состав тела, жёсткость артерий, давление). human_clinical: то, что человек чувствует и что определяет его жизнь (функция, слабость, боль, заболеваемость, госпитализации, смертность). Утверждение считается по ступеням раздельно, поэтому у одного испытания может быть «оспорено» на обеих;
  • дизайн исследования у человека: если все записи на ступени наблюдательные, это указывается («human_clinical, только наблюдательные данные»).

Что делать дальше (next_step) показывается рядом, но в рейтинг не входит: повторить на той же ступени, подняться на следующую или разрешить спор на оспоренной.

Показатели для агрегации #

Показатель считается один раз, по правилам, из проверенной карточки. Языковая модель в расчёте показателей не участвует. Неизвестное значение остаётся неизвестным (ниже).

Показатель Что измеряет Откуда считается Значения Что лучше
effect_level как далеко подтверждён эффект из проверенных утверждений none · cells · invertebrates · mammals · human_markers · human_clinical выше
robustness воспроизведён ли эффект независимо из проверенных утверждений single · replicated выше
multi_site_positive положительный результат многоцентровой программы из проверенных утверждений и базы (признак ITP/CITP у записи) no · positive положительный
mechanism подтверждены ли звенья объяснения из проверенных утверждений unverified · partial · supported выше
novelty насколько результат нов для литературы из проверенных утверждений и правил (граф знаний пока не используется) new_context < translation < analog < new_link выше
path_to_human сколько предварительных шагов до испытания на человеке из правил; данные из базы (ChEMBL, ClinicalTrials.gov) 2 · 1 · 0 шагов меньше шагов
late_start какую долю медианной продолжительности жизни составляет возраст начала вмешательства из правил; возраст из карточки, медианы из таблицы число или интервал от 0 до 1 выше
both_sexes показан ли эффект у обоих полов из проверенных утверждений one · both оба
effect_size размер эффекта на найденной ступени из проверенных утверждений (метрика записей) % изменения медианы, шкала 0–30%, значения выше 30% приравниваются к 30% больше
informativeness сколько альтернативных объяснений различает решающий эксперимент из правил по таблице предсказаний число от 0 до 4 больше

Подробности:

  • novelty. new_context: то же вмешательство и вид уже работают, но в другой линии, при другом поле, дозе или возрасте начала. translation: известная находка переносится на новый вид. analog: известное родственное вмешательство. new_link: новая связь вмешательства и исхода. Известный результат в рейтинг не входит и этих уровней не получает.
  • mechanism считается по утверждениям с ролями «механизм» и «посылка»: все подтверждены, часть, ни одно.
  • informativeness в текущей версии не считается: таблица предсказаний строится на этапе дебатов, пока значение неизвестно.
  • Шкала effect_size (0–30%) — черновое допущение.

path_to_human #

Показатель считает число предварительных шагов, которые нужны, прежде чем можно проводить испытание на человеке с маркерами или функцией в качестве исхода.

  • Нет данных о безопасности для человека: нужен пакет доклинической безопасности (+1 шаг). Данные о безопасности есть у одобренного препарата, у вещества на клинической стадии и у диеты.
  • Нет подтверждённого эффекта у млекопитающих: нужно исследование на мышах (+1 шаг).
Значение Что значит
0 безопасность для человека известна и эффект у млекопитающих подтверждён: можно сразу идти к человеку
1 не хватает одного шага
2 не хватает обоих

Если данных о безопасности не определить (ген-мишень без препарата, нераспознанное вещество), значение неизвестно.

«На момент T» в бэктесте. Вещество считается одобренным, если год первого одобрения в ChEMBL не позже года T; веществом на клинической стадии — если в ClinicalTrials.gov есть испытание с ним, начатое до T. Вопрос об эффекте у млекопитающих уже учитывает только записи, датированные не позже T.

Показатель задаёт порядок «ближе к человеку»; оценок стоимости и сроков в долларах и месяцах система не даёт.

Неизвестное остаётся неизвестным #

Если значение показателя определить нельзя, оно не заменяется средним или типичным. В каждом розыгрыше агрегации оно берётся случайно из допустимого диапазона: для порядкового показателя равномерно по уровням, для числового по всей шкале. Неопределённость данных и неопределённость весов складываются в разброс оценки гипотезы: у гипотезы с большим числом неизвестных полоса шире.

late_start #

Показатель — возраст начала вмешательства как доля медианной продолжительности жизни контрольных животных (не больше 1). Чем позже начато вмешательство, тем выше значение: эффект, полученный при позднем старте, считается более ценным.

  • Точный возраст («600 days», «20 months», «65 years») делится на медиану.
  • Словесный возраст («middle-aged», «old») даёт интервал: каждому слову соответствует возрастной промежуток своего вида (таблица в разделе о данных).
  • Медиана берётся для вида, линии и пола из карточки. Не указана линия — интервал по всем линиям вида; не указан пол — строка «оба», если она есть, иначе интервал по полам; вида нет в таблице — значение неизвестно.
  • С интервалом медиан [m₁, m₂] и возрастом a доля равна [a / m₂, min(1, a / m₁)]. Узкая или широкая полоса отражает неопределённость.

Пример: самки мышей UM-HET3 (медиана 887 суток), «old» (18–24 месяца, 548–731 сутки): доля 0,62–0,82.

Профили и АСПИД

Как порядок важности показателей превращается в рейтинг без заданных весов и что означают его числа.

Определение #

Рейтинг строится без заданных весов. Профиль задаёт только порядок важности: показатель выше по списку весит не меньше любого ниже. Веса внутри порядка много раз выбираются случайно (метод АСПИД, близкий к SMAA), и для каждой гипотезы считаются:

  • ожидание — средняя оценка по розыгрышам весов;
  • P(топ-3) — доля розыгрышей, в которых гипотеза входит в первые три;
  • P(лучшая) — доля розыгрышей, в которых она первая;
  • полоса — 5–95% оценки.

Узкая полоса и высокая P(топ-k) означают, что место устойчиво к выбору весов; широкая — что оно зависит от приоритетов. Профиль — порядок важности показателей, а не оценка гипотез: разным задачам нужны разные порядки, и выбирает его тот, кто решает, что проверять.

Идея #

АСПИД (анализ и синтез показателей при информационном дефиците) — семейство методов Н. В. Хованова: вместо одного набора весов задаются только порядок важности показателей и неопределённость данных, а веса много раз выбираются случайно. Реализация на этом сайте следует SMAA-2 (Lahdelma, Salminen), которая по постановке близка: оценка гипотезы аддитивная, веса равномерно распределены по допустимому набору, моделирование идёт по весам и по неизвестным значениям показателей.

Почему так. Веса показателей спорны, а порядок важности («проверенные данные важнее новизны») эксперт назвать может. Метод показывает, что следует из порядка при любых допустимых весах, и сколько в результате решают именно приоритеты.

Модель #

У каждой гипотезы i есть значения показателей qij от 0 до 1, где больше — лучше (показатели вроде path_to_human переворачиваются). Оценка:

u(i, w) = Σj wj · qij

  • Числовые показатели (late_start, effect_size, informativeness) переводятся в [0, 1] по фиксированным шкалам, а не по минимуму и максимуму текущего набора. Поэтому значение гипотезы и вероятность «A выше B» не зависят от того, какие ещё гипотезы в наборе; места, конечно, зависят.
  • Порядковые показатели (effect_level, robustness, multi_site_positive, mechanism, novelty, path_to_human, both_sexes): в каждом розыгрыше уровни получают случайные числа, возрастающие вместе с уровнем (отображение SMAA-O). Так не нужно выбирать, что «mammals» вдвое лучше «invertebrates»; равные шаги можно включить для проверки чувствительности.
  • Неизвестные значения разыгрываются по допустимому диапазону (см. «Показатели»).
  • Оценка компенсаторная: высокое значение по одному показателю может покрыть низкое по другому. Отсев опровергнутых гипотез происходит до агрегации (фильтр).

Веса и профили #

Допустимые веса — неотрицательные, сумма равна 1. Профиль приоритетов ограничивает их линейно: показатель ступени выше весит не меньше любого показателя ступени ниже; показатели одной ступени равноправны и разыгрываются случайно. Показатели, которых в профиле нет, порядком не заданы (если нет ступени «остальные»).

Профиль Порядок важности (версия draft-2)
Приоритет: проверенные данные (evidence_first) 1: уровень эффекта, устойчивость, механизм · 2: все остальные
Приоритет: осуществимость (cheap_feasible) 1: путь к человеку · 2: новизна · 3: уровень эффекта · остальные порядком не заданы
Приоритет: понимание механизма (fundamental) 1: механизм, информативность, новизна · 2: путь к человеку · остальные порядком не заданы

Профили — примеры, а не рекомендации; с экспертами они не согласованы. Рейтинг считается отдельно для каждого профиля, и результаты всегда показываются вместе с версией профиля.

Как выбираются веса. Когда порядок задан для всех показателей, веса выбираются точно: отсортированный равномерный набор, самые большие значения достаются первой ступени. Для остальных профилей и для ограничений другого вида используется метод hit-and-run: случайное блуждание, равномерное по допустимому многограннику (Tervonen et al. 2013).

Что считается #

Все числа получены за один проход по K розыгрышам (10 000 по умолчанию). Для всех гипотез используются одни и те же розыгрыши, поэтому разности согласованы.

Величина Определение Как читать
Ожидание средняя оценка по розыгрышам чем выше, тем лучше при «типичных» весах
Полоса 5–95% оценки по розыгрышам узкая: оценка почти не зависит от весов и данных; широкая: зависит
P(топ-k) доля розыгрышей, в которых гипотеза среди первых k устойчивость места; по умолчанию k = 3
P(лучшая) доля розыгрышей, в которых гипотеза первая
P(A выше B) доля розыгрышей, в которых оценка A больше оценки B матрица на странице «Рейтинг»
Распределение мест доля розыгрышей для каждого места в данных прогона
Центральные веса средний вектор весов, при которых гипотеза первая какие приоритеты её выдвигают
Фактор уверенности вероятность быть первой при фиксированных центральных весах, когда меняются только данные хватает ли данных, чтобы отличить гипотезу от остальных

Гипотеза с узкой полосой и высокой P(топ-k) занимает устойчивое место при любых допустимых весах. Широкая полоса означает, что место зависит от приоритетов или от неизвестных значений. Если P(топ-k) высока в каждом профиле, гипотеза — надёжный кандидат; различия между профилями показывают, что выберет каждая цель.

Точность #

У моделирования есть собственная погрешность, и она разная для разных чисел.

  • Вероятности (P(топ-k), P(лучшая), P(A выше B)) — доли розыгрышей. С доверием 95% их погрешность равна 1,96·√(p(1−p)/K); в худшем случае (p = 0,5) для K = 10 000 она составляет ±0,0098, а чтобы получить ±0,01, нужно K = 1,96² / (4·0,01²) ≈ 9 604 розыгрыша.
  • Ожидание — среднее по розыгрышам; его погрешность равна 1,96·σ/√K, где σ — разброс оценки гипотезы. Типичный разброс 0,05–0,10 даёт ±0,001–0,002 при K = 10 000.

Если оценки двух гипотез различаются меньше этой погрешности (для пары: 1,96·√((σA² + σB²)/K)), они считаются равными, и таблица рейтинга объединяет их в одно место «на равных». «На равных» означает лишь, что различие не отличимо от шума моделирования, а не что гипотезы похожи по смыслу. Насколько места зависят от весов и данных, показывают полоса и матрица P(A выше B), а не погрешность.

Вместе с результатом сохраняются K, зерно случайных чисел, версия профиля и тип отображения порядковых уровней.

Ограничения вида «A не хуже B» #

Эксперт может выбрать из пары гипотез «A не хуже B» при данном профиле. Выбор превращается в линейное ограничение на веса: Σj wj (qAj − qBj) ≥ 0. Профиль получает новую версию, а веса выбираются методом hit-and-run.

  • Если у A или B есть неизвестные значения, они заменяются ожидаемыми, а ограничение помечается как приближённое.
  • Если ограничения противоречат друг другу, допустимых весов нет. Система показывает минимальный набор противоречащих выборов и никогда не отбрасывает ответ молча.
  • Результаты всегда доступны и с выборами эксперта, и без них.
  • Следующую пару для вопроса выбирают среди лучших гипотез: пара, для которой P(A выше B) ближе всего к 0,5.

Ограничения метода #

  • Коррелированные показатели считаются дважды. Уровень эффекта и устойчивость выводятся из одних и тех же данных, поэтому аддитивная оценка может завышать их суммарный вес.
  • Шкалы линейные. Нелинейные функции нормировки из работ Хованова не используются; границы шкал (например, 30% для размера эффекта) — рабочие допущения.
  • Зависимые неопределённости между показателями не моделируются: разыгрываются независимо.
  • Рейтинг зависит от выбранного профиля. Это свойство метода, а не недостаток: профиль и есть заданная цель.

Правило «на момент T» #

Бэктест оценивает рейтинг так, как если бы сегодня была дата T, а результаты стали известны позже. Чтобы будущее не просочилось в рейтинг:

  • у каждой записи есть дата: для PubMed это самая ранняя публичная дата (электронная публикация, печатная, попадание в PubMed); для испытаний — дата начала; для DrugAge — дата работы по PMID;
  • поиск ограничен датой: учитываются только работы, опубликованные не позже T;
  • для каждого прогона бэктеста выполняется аудит дат: ни одна запись с датой позже T не должна попасть ни в один компонент (проверенные утверждения, альтернативы, отказы);
  • знания языковой модели датой не ограничиваются. Устройство проверки уменьшает утечку: текст разбирается без внешних фактов, а статус требует дословной цитаты из работы, опубликованной до T. Полностью утечку это не исключает, поэтому наборов два: чистый (исходы появились после даты отсечки знаний используемой модели; на нём системы сравниваются) и исторический (T = 2010; модели могли знать исходы, поэтому на нём оценивается только эта система).

Показатель path_to_human в бэктесте тоже считается «на момент T» (год первого одобрения, начало испытаний; см. «Показатели»).

Какие проверки возможны на открытых данных #

Гипотезу можно проверять не только литературой: многие её следствия проверяются открытыми данными (идея в духе проверки следствий по Попперу). Сначала тест записывается до просмотра данных (набор данных, переменная, сравнение, направление, статистика, порог), затем выполняется, а результат хранится как запись типа C. В текущей версии системы эти проверки не реализованы; ниже то, что они позволят проверить.

Пять разобранных вручную карточек. Каждая показывает одно правило проверки на реальной литературе.

Карточки построены вручную по описанному формату; цитаты дословно взяты из аннотаций PubMed. Они же служат проверочными примерами для нормализатора и верификатора. Кнопка «Открыть карточку» загружает набор примеров и показывает её в разделе «Карточка» на главной странице.

Пример 1. Рапамицин и здоровая продолжительность жизни у людей #

«Weekly low-dose intermittent rapamycin, by inhibiting mTORC1, slows multiple aspects of aging and can improve healthspan in healthy older adults, as it does in mice where it extends lifespan even when started late in life.»

Чему учит: подгруппа и несовпадение вида. Результат у мышей сильный и повторён на трёх площадках ITP, но у людей исход оспорен: в испытании PEARL положительны подгруппа женщин на 10 мг и вторичные исходы, а первичный исход нулевой. Утверждение «замедляет старение у человека» держится только на данных мышей, которые из-за унаследованного вида «человек» уходят в мягкий отказ. Посылка «рапамицин ингибирует mTORC1» известна, но в найденных аннотациях упомянута только как фон, поэтому «не проверена».

Пример 2. Сенолитики и физическая функция #

«Intermittent dasatinib plus quercetin improves physical function in older adults because it clears senescent cells and lowers their inflammatory secretions (SASP), which drive physical decline.»

Чему учит: строгое совпадение контекста. Данные на эксплантах человеческой жировой ткани — не то же, что приём людьми, а пилотное исследование на больных идиопатическим лёгочным фиброзом — не то же, что здоровые пожилые люди. Пример 3. Почему рапамицин продлевает жизнь #

«Rapamycin extends mouse lifespan mainly by postponing death from cancer, not by slowing aging itself.»

Чему учит: контраст «X, а не Y». Исход — объяснение X, отвергаемое объяснение Y проверяется как отдельное утверждение. Для Y независимые работы расходятся (Wilkinson 2012 за, Neff 2013 против), поэтому Y и весь исход оспорены, а гипотеза остаётся в рейтинге и показывает спор. В одной аннотации различаются «может быть» (предположение) и результат.

Пример 4. Допуск: расплывчатая гипотеза #

«Senolytics slow aging.»

Чему учит: допуск и уточнение. В тексте нет вида, нет вещества (класс препаратов) и нет измеримого исхода, поэтому гипотеза идёт в список «ждут уточнения» с перечнем недостающих полей. Два уточнённых варианта показывают, зачем уточнение: один уже известен (нулевая новизна), другой открыт и проверяем. «Senescent cells are bad for health» не гипотеза: нет вмешательства и измеримого исхода, текст хранится как направление.

Границы применимости

На что рассчитан рейтинг и какие вопросы остаются открытыми.

Границы применимости #

  • Проверка идёт по аннотациям статей; полные тексты пока не используются.
  • В этом прогоне источники — PubMed и DrugAge. Другие базы описаны в разделе «Данные и проверки» как возможные, а не подключённые.
  • Дословность цитат проверяется программно, уместность цитаты (о том ли она, подтверждает ли утверждение, в каком контексте) оценивает языковая модель. Два прогона могут немного различаться: PubMed возвращает выдачу не детерминированно, поэтому по каждому утверждению читаются 20 аннотаций.
  • Рейтинг упорядочивает гипотезы по проверенным данным при выбранных приоритетах; это не прогноз результата эксперимента.
  • Отрицательные результаты в литературе представлены реже; это стоит иметь в виду при чтении оценок. Многоцентровые программы (ITP, CITP) публикуют и отрицательные результаты, это самые чистые данные.
  • Профили приоритетов — примеры; содержание порядка задаёт пользователь.
  • Лучше всего подходят гипотезы о вмешательствах и механизмах старения (что, кому, в какой дозе, с каким исходом). Гипотезы без измеримого исхода уходят в списки «ждут уточнения» и «не разобраны».
  • Флаг retracted в схеме есть и исключает запись, но автоматически его в этой версии не выставляют.
  • Модели могли знать исходы исторического бэктеста (T = 2010), поэтому он используется только для оценки самой системы, а не для сравнения с другими.

Открытые вопросы #

Шкалы и пороги.

  • Границы фиксированных шкал для числовых показателей (30% для размера эффекта; насыщение для информативности) — рабочие допущения. Порог размера эффекта в критериях решения: по умолчанию заявленный в гипотезе, иначе «любой значимый эффект»; взять его из эталонного класса (например, типичные +10–20% к медиане жизни в ITP) предстоит решить.
  • Показатель path_to_human трёхуровневый. Оценки стоимости и сроков (классы в долларах, длительность по виду исхода) нужны только при спросе на них.

Показатели.

  • Показатели, выводимые из одних данных (уровень эффекта и устойчивость), при суммировании считаются дважды. Нужно проверить корреляции на реальных карточках и при необходимости объединить показатели или ограничить веса.
  • Новизна считается по проверенным утверждениям; сопоставление с графом знаний ещё не реализовано.
  • Информативность определена, но пока не считается: таблица предсказаний строится вместе с дебатами.
  • Ограничение «A не хуже B» от эксперта при неизвестных значениях использует их ожидания и помечается как приближённое; точная обработка не решена.

Карточка и словарь.

  • Для комплексов (например, mTORC1) предлагается брать идентификатор Complex Portal для вида, если он есть, иначе термин GO о клеточном компоненте (mTORC1: GO:0031931).
  • Список альтернативных объяснений расширяется по мере появления новых типов ошибок.
  • Частые пометки other в списке «не разобраны» — кандидаты на расширение словаря отношений.

Данные.

  • Проверки на открытых данных (раздел «Данные и проверки») пока не реализованы, а условия доступа к источникам нужно перепроверять.
